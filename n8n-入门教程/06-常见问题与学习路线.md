## 1. 新手常见问题排查表 / Common Issues & Fixes

### 1.1 安装 / 启动问题

| 现象 | 原因 | 解决办法 |
|------|------|---------|
| 浏览器打不开 localhost:5678 | n8n 进程没在运行 | 检查终端窗口是否还开着、有没有报错；Ctrl+C 后重新运行启动命令 |
| Docker 拉取镜像很慢/超时 | 境外镜像源慢 | 配置国内镜像加速器（见第 02 章）；或换 npm 方式安装 |
| Docker 启动后端口被占用 | 5678 端口被其他程序占用 | 换端口：把 `-p 5678:5678` 改成 `-p 5679:5678`，访问 localhost:5679 |
| n8n 启动后数据丢了 | 没挂数据卷 | 必须用第 02 章命令里的 `-v n8n_data:/home/node/.n8n`，否则容器重建数据就没了 |

### 1.2 网络 / 访问问题（本土化重点）

| 现象 | 解决办法 |
|------|---------|
| n8n Cloud 注册/登录打不开 | 使用自部署（Docker/npm），见第 02 章 |
| NASA API 获取不到数据 | ① 确认密钥有效 ② 国内网络下 api.nasa.gov 偶尔不通，可换第 03 章第 7 节的替代练习方案 |
| Postbin 打不开 / 创建 bin 失败 | 用 webhook.site 等替代；或把输出节点换成 Gmail/Telegram 通知 |
| 定时触发器时间不对 | 自部署时检查时区：Docker 加 `-e GENERIC_TIMEZONE="Asia/Shanghai" -e TZ="Asia/Shanghai"` |

### 1.3 节点 / 数据问题

| 现象 | 原因与解决 |
|------|-----------|
| 节点报错 "Credentials are not set"（未设置凭据） | 该服务需要凭据，按第 03 章 Step 3 的方式创建并选择凭据 |
| 表达式报 "Can't get data"（取不到数据） | 被引用的节点还没执行过——先 Execute step 它 |
| 表达式报 "Invalid syntax"（语法错误） | 检查拼写，或删掉重新拖拽生成（见第 04 章第 5 节） |
| OUTPUT 数据比预期多/少 | 节点默认会逐条处理输入数据，检查上游节点输出条数；需要「只处理一次」的场合用聚合（Aggregate）节点 |
| 引用的字段名找不到 | 字段名大小写、空格是否一致；嵌套字段要用 `{{$json.body.city}}` 逐层取 |

> 💡 **通用排查口诀**：**先看节点报错原文 → 去官方手册搜这个报错 → 检查上游节点执行了吗 → 检查凭据 → 检查字段名**。

## 4. 给新手的最后建议 / Final Advice

1. **先抄后创**：从模板库里导入现成工作流，拆开看懂，再改成自己的需求——这是最快的上手路径。
2. **小步快跑**：每次只加一个节点，跑通再加下一个。一次搭 10 个节点出错时极难排查。
3. **善用测试**：`Execute step`（单节点测试）+ **数据固定（Pin Data）**——把测试数据固定住，开发时不用反复请求外部服务。
4. **保留官方手册**：`docs/` 目录就是你的离线官方手册，学会用关键词搜它，比任何教程都管用。
5. **动手做一个小项目**：比如「每天早上把天气 + 今日待办发到微信/Telegram」，把第 03 章学到的技能全部用上，你就入门了！🎉
