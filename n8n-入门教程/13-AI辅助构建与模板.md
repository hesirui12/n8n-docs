## 1. 模板库 / Workflow Templates

> **官方原文**：Templates provide: Help getting started; Examples of what you can build; Best practices for creating your own workflows.
> **翻译**：模板能帮你快速起步、展示可以做什么、提供自己搭建的最佳实践范例。

**怎么用**：

1. 在新建工作流时选择 **Templates（模板）** 图标，或 n8n 顶部 **Templates** 入口。
2. 进入官方模板库：<https://n8n.io/workflows/>（自部署企业版可配置自建模板库）。
3. 浏览/搜索 → 选中 → **Use workflow（使用）** 导入你的实例。
4. **导入后要自己补**：模板里的**凭据是示例**，需要你创建并选择真实凭据；部分配置（URL、参数）要按你的环境调整。

> 💡 **新手黄金路径**：先抄后创——导入一个跟你需求相近的模板，拆开看懂每一步，再改成自己的。这是官方认可的成长路径。

**官方重点模板**（本教程提到过的）：

| [RAG Starter Template](https://n8n.io/workflows/5010-rag-starter-template-using-simple-vector-stores-form-trigger-and-openai) | 知识库问答（第 12 章） |

## 2. AI Assistant / 对话式搭流程

> 官方出处：`ways-of-building-workflows/ai-assistant.md`、`use-the-ai-assistant.md`

**AI Assistant（AI 助手）** 是 n8n 里基于聊天的构建助手（**目前仅 n8n Cloud**，Preview 功能）：你描述需求，它帮你**规划、搭建、测试、修 Bug**。

**能帮你干什么**：

- **创建工作流**：描述自动化需求 → 生成工作流
- **编辑工作流**：加节点、改逻辑、调配置
- **测试和排错**：检查失败执行、解释原因、给修复建议
- **辅助建 Agent**：建议指令、工具、技能
- **管理资源**：需要时创建/更新数据表等

**写出好提示的要点**（官方建议）：说清楚**触发条件**、用哪些**应用/服务**、读写哪些**数据**、成功/失败时**做什么**、是否要先确认再发布。

**安全机制**：

- 你的**密钥永远不会发给 AI**——需要凭据时，它在聊天里弹一张「凭据卡」，让你在标准界面选择或新建，而不是把 Key 粘进对话。
- 高影响操作（发布、删除）会**先征求你确认**。
- AI 生成的工作流**必须人工审查**后再上线。

> 💡 **写提示模板**：
> "Create a workflow that checks Gmail every morning for invoices, saves PDF attachments to Google Drive, and adds a row to a Data Table. Ask me before publishing the workflow."

## 3. AI Workflow Builder / 自然语言生成工作流

> 官方出处：`ways-of-building-workflows/ai-workflow-builder.md`（Beta，hidden 页面）

**AI Workflow Builder** 用自然语言描述目标 → 它自动完成节点选择、摆放和配置，并可以**迭代优化**：

1. **Describe**：描述需求或选示例提示词
2. **Monitor**：实时观看构建过程
3. **Review & refine**：检查凭据和参数，用对话继续修改

**计费**：每次「创建或修改」的对话算 1 次交互 = 1 个 credit（失败的生成不算）。

**隐私**：会发送你的提示词、节点定义和模拟执行数据给 LLM；**不会**发送你的凭据和过去的执行记录。

## 4. Chat Hub / 统一 AI 聊天入口

> 官方出处：`ways-of-building-workflows/chat-hub.md`（Beta）

**Chat Hub** 是 n8n 里集中的 AI 聊天界面（左侧导航 **Chat**）：

- 直接和多个模型聊天（不用搭工作流）
- **Personal Agents**：创建带自定义指令的个人小助手
- **Workflow Agents**：把你自己搭的 AI 工作流（需 Chat Trigger + Agent 开启 streaming + 发布）放进模型选择器，团队成员也能用
- **Chat user 角色**：只看聊天界面、不用碰工作流的人（Starter+ 计划）

> 💡 想把工作流变成「产品」发给同事用，Chat Hub + Workflow Agent 是最顺的路。

## 5. 社区节点 / Community Nodes

> 官方出处：`docs/integrations/README.md`（`integrations/community-nodes/`）

n8n 有 **400+ 内置节点**，还不够？社区（Community）节点能装别人写好的扩展：

| 内容 | 说明 |
|------|------|
| **内置节点** | n8n 官方维护，界面内直接搜索使用 |
| **社区节点** | 社区开发者发布到 npm 的扩展，功能五花八门 |
| **自定义节点** | 你/公司自己开发的私有节点（`docs/connect/create-nodes/` 有教程） |

**装社区节点**（Settings → Community Nodes → Install，填 npm 包名）：

```text
包名示例：n8n-nodes-basecamp2
```

> ⚠️ **安全提醒**：社区节点是第三方代码，安装前确认来源可信、查看下载量和维护活跃度。生产实例上谨慎安装不明来源的包。

## 6. 一句话总结 / TL;DR

```
起步：Templates 模板库导入现成工作流，先抄后创
Cloud 用户：AI Assistant 聊天搭流程（记得人工审查 + 密钥不进聊天）
尝鲜：AI Workflow Builder 自然语言生成；Chat Hub 统一聊天
扩展：内置 400+ 节点不够 → 社区节点（npm 包，注意安全）
```
