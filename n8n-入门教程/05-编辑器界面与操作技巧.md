## 1. 画布与节点面板 / Canvas & Node Panel

| 界面元素 | 中文 | 说明 |
|---------|------|------|
| **Canvas** | 画布 | 编辑器主区域，你在上面摆放和连接节点 |
| **Node Panel** | 节点面板 | 按 `N` 键或在空白处双击打开的节点选择器，可搜索/浏览所有节点 |
| **Add first step** | 添加第一步 | 空画布上的按钮，打开节点面板并只显示**触发器**（因为工作流第一节点必须是触发器） |
| **Add node** 连接点 | 添加节点连接点 | 节点右侧的小圆点，点它从当前节点往下接新节点 |

> 💡 **官方提示**：如果你要的是「某 App 的事件触发」，在节点面板选 **On App Event**，会列出所有支持的集成；不是所有集成都有触发器，选中节点后触发器会显示在操作列表**顶部**（Recommended 区）。

## 2. 节点的基本操作 / Node Controls

鼠标悬停在画布上的节点，会出现一排操作按钮：

| 按钮 | 作用 |
|------|------|
| **Execute step**（▶） | 只执行这一个节点（以及为它提供输入的节点）——**调试利器** |
| **Deactivate**（⏻） | 停用节点：执行时跳过它，但保留配置 |
| **Delete**（🗑） | 删除节点 |
| **节点菜单**（⋯） | 更多操作：Open、Rename、Pin（固定数据）、Copy、Duplicate（复制）、Convert to sub-workflow（转为子工作流，第 08 章）等 |

**连线的两种方式**：

1. 从节点右侧的连接点拖到下一个节点左侧。
2. 用节点菜单里的 **Copy（复制）+ Ctrl/Cmd + V（粘贴）** 也可以复制节点到任意位置。

## 3. 节点设置项详解 / Node Settings

打开节点的 **Settings（设置）** 选项卡，可以控制节点的行为。官方手册逐个解释了这些开关：

| 设置项 | 中文 | 作用 |
|--------|------|------|
| **Always Output Data** | 总是输出数据 | 节点没数据时也返回一个空项。⚠️ 别用在 If 节点上，可能造成死循环 |
| **Execute Once** | 只执行一次 | 收到 10 条数据也只处理第 1 条（比如只给第一位客户发消息） |
| **Retry On Fail** | 失败重试 | 执行失败时自动重跑，直到成功 |
| **On Error** | 出错时 | 见下表 ↓ |
| **Notes** | 节点备注 | 给节点写说明文字 |
| **Display note in flow** | 在画布显示备注 | 开启后备注会以小字显示在节点下方 |

**On Error（出错时）三种策略**：

| 策略 | 行为 |
|------|------|
| **Stop Workflow** | 整个工作流立刻停止（默认） |
| **Continue** | 跳过报错继续跑，用上一次的有效数据 |
| **Continue (using error output)** | 继续跑，并把错误信息传给下一个节点（可以在下游自己处理） |

> 💡 **小白建议**：给重要节点开 **Retry On Fail**，给「失败也想继续」的流程开 **Continue**。

## 4. 便利贴与画布分组 / Sticky Notes & Canvas Groups

> **官方原文**：This section contains: **Nodes**, **Connections**, **Sticky notes** (document your workflows), **Canvas Groups** (organize related nodes).
> **翻译**：本部分包含：**节点**、**连接**、**便利贴**（记录说明）、**画布分组**（整理相关节点）。

| 零件 | 怎么用 | 快捷键 |
|------|--------|--------|
| **Sticky Note（便利贴）** | 画布空白处写说明，团队协作/自己回看都靠它 | `Shift + S` 添加 |
| **Canvas Group（画布分组）** | 选中几个节点 → 右键/快捷键组合成组，框住一段逻辑 | 选中后 `Ctrl/Cmd + G` 分组，`Ctrl/Cmd + Shift + G` 取消 |

> 💡 **小白建议**：工作流超过 4~5 个节点时，养成「加便利贴 + 分组」的习惯，一周后回来看自己还能看懂。

## 5. 高频键盘快捷键 / Keyboard Shortcuts

> 官方出处：`docs/build/keyboard-shortcuts.md`。以下都是官方手册原表精选。

### 工作流级 / Workflow

| 快捷键 | 作用 |
|--------|------|
| `Ctrl/Cmd + S` | 保存当前工作流（其实是打开版本命名弹窗） |
| `Ctrl/Cmd + Enter` | 执行整个工作流 |
| `Ctrl/Cmd + Alt + N` | 新建工作流 |
| `Ctrl/Cmd + O` | 打开工作流 |
| `Ctrl/Cmd + Z` / `Shift + Ctrl/Cmd + Z` | 撤销 / 重做 |

### 画布导航 / Canvas

| 快捷键 | 作用 |
|--------|------|
| `Space` + 拖拽 或 `Ctrl/Cmd + 鼠标左键` + 拖拽 | 平移画布 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 重置缩放 |
| `1` | 缩放到适配整个工作流 |

### 节点操作 / Nodes

| 快捷键 | 作用 |
|--------|------|
| 双击节点 | 打开节点设置 |
| `Ctrl/Cmd + A` | 全选节点 |
| `Ctrl/Cmd + C` / `V` | 复制 / 粘贴节点 |
| `Delete` | 删除选中节点 |
| `D` | 停用选中节点 |
| `F2` | 重命名节点 |
| `P` | 固定（Pin）节点数据 |
| `Enter` | 打开选中节点 |
| `Shift + S` | 添加便利贴 |

### 节点内 / Inside Nodes

| 快捷键 | 作用 |
|--------|------|
| `=` | 在空的参数输入框里，快速切换为表达式模式 |

### 命令面板 / Command Bar

| 快捷键 | 作用 |
|--------|------|
| `Ctrl/Cmd + K` | 打开 **Command Bar（命令面板）** |

> 💡 **命令面板是什么？** 一个万能搜索框：可以加节点、保存/测试/发布/复制/导入导出工作流、打开工作流/凭据/数据表/项目、调试/重试/停止执行、访问模板/变量/设置/文档。**记不住菜单在哪，就按 `Ctrl+K`。**

---

## 6. 一句话总结 / TL;DR

- 空白处或按 `N` 开节点面板；节点右侧圆点往下接节点
- 悬停节点出工具栏：执行单步、停用、删除、菜单
- 复杂流程用「便利贴 + 分组」管理可读性
- 记不住操作就按 `Ctrl/Cmd + K` 命令面板
- `P` 固定数据、`D` 停用节点、`Ctrl+Enter` 跑全流程
