## 1. 新手常见问题排查表 / Common Issues & Fixes

### 1.1 安装 / 启动问题

| 现象 | 原因 | 解决办法 |
|------|------|---------|
| 浏览器打不开 localhost:5678 | n8n 进程没在运行 | 检查终端窗口是否还开着、有没有报错；Ctrl+C 后重新运行启动命令 |
| Docker 拉取镜像很慢/超时 | 境外镜像源慢 | 配置国内镜像加速器（见第 02 章）；或换 npm 方式安装 |
| Docker 启动后端口被占用 | 5678 端口被其他程序占用 | 换端口：把 `-p 5678:5678` 改成 `-p 5679:5678`，访问 localhost:5679 |
| n8n 启动后数据丢了 | 没挂数据卷 | 必须用 `-v n8n_data:/home/node/.n8n`，否则容器重建数据就没了 |
| npm 安装报 Node 版本错 | 版本不匹配 | n8n 要求 Node.js **20.19 ~ 24.x**，升级/降级 Node 版本 |

### 1.2 网络 / 访问问题（本土化重点）

| 现象 | 解决办法 |
|------|---------|
| n8n Cloud 注册/登录打不开 | 使用自部署（Docker/npm），见第 02 章 |
| NASA API 获取不到数据 | ① 确认密钥有效 ② 国内网络下 api.nasa.gov 偶尔不通，可换第 03 章第 7 节的替代练习方案 |
| Postbin 打不开 / 创建 bin 失败 | 用 webhook.site 等替代；或把输出节点换成 Gmail/Telegram 通知 |
| 定时触发器时间不对 | 检查时区：Docker 加 `-e GENERIC_TIMEZONE="Asia/Shanghai" -e TZ="Asia/Shanghai"`；或在工作流设置里设 Timezone |
| OpenAI 等 AI 接口连不上/支付不便 | 换国内模型供应商：DeepSeek、通义千问、Kimi、GLM（第 12 章） |

### 1.3 节点 / 数据问题

| 现象 | 原因与解决 |
|------|-----------|
| 节点报错 "Credentials are not set"（未设置凭据） | 该服务需要凭据，按第 09 章的方式创建并选择凭据 |
| 表达式报 "Can't get data"（取不到数据） | 被引用的节点还没执行过——先 Execute step 它（第 04 章） |
| 表达式报 "Invalid syntax"（语法错误） | 检查拼写，或删掉重新拖拽生成（第 04 章） |
| Code 节点报 "Please return an array of items" | All Items 模式必须返回数组 `[{ json: {...} }]`（第 11 章） |
| 节点边框变黄（Dirty Node） | 你改过配置，输出过期了——重新执行一次即可（第 07 章） |
| OUTPUT 数据比预期多/少 | 节点默认逐条处理输入；需要「只处理一次」用 Settings → Execute Once 或聚合节点 |
| 引用的字段名找不到 | 字段名大小写、空格是否一致；嵌套字段用 `{{$json.body.city}}` 逐层取 |

> 💡 **通用排查口诀**：**先看节点报错原文 → 去官方手册搜这个报错 → 检查上游节点执行了吗 → 检查凭据 → 检查字段名**。

### 1.4 执行 / 发布问题

| 现象 | 原因与解决 |
|------|-----------|
| 定时器不自动跑 | 没发布（Publish）——草稿不触发定时器（第 06 章） |
| Webhook 地址没生效 | 同上，发布后 Webhook 才用生产地址 |
| 执行配额消耗快 | 生产执行才计费；测试用手动执行 + Pin 数据（第 07 章） |
| 想重试失败的执行 | Executions 列表点 Refresh（重试） |
| 想用失败数据复现 Bug | Executions → Debug in editor（第 07 章） |
| 发布按钮灰色 | 看发布按钮状态提示：有错误需先修 / 无可发布改动（第 06 章） |

## 4. 给新手的最后建议 / Final Advice

1. **先抄后创**：从模板库里导入现成工作流，拆开看懂，再改成自己的需求——这是最快的上手路径。
2. **小步快跑**：每次只加一个节点，跑通再加下一个。一次搭 10 个节点出错时极难排查。
3. **善用测试**：`Execute step`（单节点测试）+ **Pin Data（数据固定）**——把测试数据固定住，开发时不用反复请求外部服务（第 04 章）。
4. **遇到失败别慌**：Executions 列表 → Debug in editor → 用真实数据复现 → 修 → 重试（第 07 章）。
5. **保留官方手册**：`docs/` 目录就是你的离线官方手册，学会用关键词搜它，比任何教程都管用。
6. **动手做一个小项目**：比如「每天早上把天气 + 今日待办发到微信/Telegram」，把第 03 章学到的技能全部用上，你就入门了！🎉
7. **AI 能力别浪费**：做完基础工作流，试试第 12 章——接一个大模型，做你的「知识库问答机器人」，成就感拉满。
