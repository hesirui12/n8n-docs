## 1. n8n 是什么？/ What is n8n?

先看官方手册怎么定义：

> **官方原文（英文）**：
> "n8n is a fair-code licensed workflow automation tool that combines AI capabilities with business process automation."
>
> **中文翻译**：n8n 是一款采用 fair-code（公平代码）许可的工作流自动化工具，它把 **AI 能力**和**业务流程自动化**结合在一起。

用大白话说：

- **自动化工具**：让软件帮你自动完成重复的工作。比如「每天 9 点自动抓取新闻发到你的邮箱」「收到表单自动给客户回信」。
- **工作流（Workflow）**：把一件完整的事情拆成一步步，让 n8n 按顺序执行。
- **可视化、无需代码**：你在网页上用鼠标把各个「零件」连起来，就像拼乐高，不用写代码。
- **能接 AI**：内置 AI Agent（AI 代理）能力，可以调用大模型（LLM）帮你处理文字、做决策。

### n8n 适合谁用？

| 人群 | 用 n8n 做什么 |
|------|--------------|
| 运营/市场人员 | 自动发邮件、整理表格、同步客户数据 |
| 个人爱好者 | RSS 监控、每日摘要、签到打卡、通知推送 |
| 开发者 | 快速搭建自动化脚本、API 集成、AI 应用原型 |
| 小团队 | 把公司里的重复流程自动化 |

> 💡 **小白提示**：你可以把 n8n 想象成「乐高 + 瑞士军刀」——积木块（节点）有很多种，每个积木做一件小事，连起来就能完成大事。

## 2. 核心概念速览 / Key Concepts at a Glance

这 5 个概念是 n8n 的骨架，第 03 章你会亲手用到它们：

### 2.1 工作流 / Workflow

> **官方原文**：An n8n workflow is a collection of nodes that automate a process. Workflows begin execution when a trigger condition occurs and execute sequentially to achieve complex tasks.
>
> **翻译**：n8n 工作流是一组节点的集合，用于自动化某个流程。当触发条件发生时，工作流开始执行，并按顺序运行以完成复杂任务。

**大白话**：一张「流程图」，上面摆着一串节点，数据像水流一样从左到右流过。

```
（示意图）
 [触发器] ──→ [获取数据] ──→ [判断/处理] ──→ [发送结果]
```

### 2.2 节点 / Node

> **官方原文**：In n8n, nodes are individual components that you compose to create workflows. Nodes define when the workflow should run, allow you to fetch, send, and process data, can define flow control logic, and connect with external services.
>
> **翻译**：在 n8n 中，节点是你组合成工作流的独立组件。节点定义工作流何时运行、允许你获取/发送/处理数据、可以定义流程控制逻辑，并与外部服务连接。

**大白话**：节点就是「积木块」。每一个节点做一件具体的小事：定时启动、请求某个网站的数据、发邮件、做判断……n8n 内置了 400+ 个节点，对应各种服务（Gmail、Slack、Telegram、数据库、HTTP API 等）。

### 2.3 触发器 / Trigger Node

> **官方原文**：A trigger node is a special node responsible for executing the workflow in response to certain conditions. All production workflows need at least one trigger to determine when the workflow should run.
>
> **翻译**：触发器是一种特殊节点，负责在特定条件下执行工作流。所有生产环境的工作流至少需要一个触发器来决定何时运行。

**大白话**：触发器是工作流的「起跑枪」。常见触发器：

- **定时触发（Schedule Trigger）**：每天/每周/每月固定时间跑一次
- **Webhook 触发**：别人访问一个链接时触发
- **表单触发**：用户提交表单时触发
- **手动触发（Execute Workflow 按钮）**：你自己点一下按钮运行

### 2.4 凭据 / Credential

> **官方原文**：In n8n, credentials store authentication information to connect with specific apps and services. After creating credentials with your authentication information (username and password, API key, OAuth secrets, etc.), you can use the associated app node to interact with the service.
>
> **翻译**：在 n8n 中，凭据存储连接特定应用和服务的认证信息。创建好凭据后，就可以用对应的节点与那个服务交互。

**大白话**：凭据就是「钥匙」。要连接 Gmail、NASA API、数据库，你需要提供对应的账号密码或 API Key（应用程序接口密钥）。n8n 会安全地帮你保管这些钥匙。

> ⚠️ **安全提示**：凭据是私密信息，不要把它分享给任何人，也不要在截图里泄露。

### 2.5 表达式 / Expression

> **官方原文**：In n8n, expressions allow you to populate node parameters dynamically by executing JavaScript code. Instead of providing a static value, you can use the n8n expression syntax to define the value using data from previous nodes, other workflows, or your n8n environment.
>
> **翻译**：在 n8n 中，表达式允许你通过执行 JavaScript 代码来动态填充节点参数。你不需要提供固定值，而是可以用表达式语法，根据前面节点的数据来定义值。

**大白话**：表达式就是「动态取值」。比如你想把上一节点返回的 `天气` 字段塞进邮件内容里，就用 `{{ $json.天气 }}` 这种写法。**你不需要会写 JavaScript**，大多数情况用拖拽就能生成表达式（第 03、04 章会演示）。

## 3. 中英对照术语速查表 / Bilingual Glossary

> 以下术语全部来自官方手册 `key-concept-glossary.md`，做了精选和翻译。**不用背，遇到不认识回来查就行。**

### 3.1 基础界面 / Basic UI

| 英文术语 | 中文 | 一句话解释 |
|---------|------|-----------|
| **Workflow** | 工作流 | 一组节点的集合，完成一个自动化流程 |
| **Node** | 节点 | 工作流里的一个积木块，做一件具体的事 |
| **Canvas** | 画布 | n8n 编辑器主区域，你在上面摆放和连接节点 |
| **Editor** | 编辑器 | n8n 的可视化编辑界面 |
| **Trigger Node** | 触发器节点 | 决定工作流何时启动的特殊节点 |
| **Connection** | 连接线 | 节点之间的连线，数据沿连线流动 |
| **Execution** | 执行 | 工作流实际运行一次的过程 |
| **Sticky Note** | 便利贴 | 画布上写说明文字的便签（团队协作很有用） |
| **Canvas Group** | 画布分组 | 把相关节点框成一组的整理工具 |
| **Template** | 模板 | 官方/社区做好的现成工作流，可直接导入使用 |
| **Sub-workflow** | 子工作流 | 被其他工作流调用的工作流 |

### 3.2 数据相关 / Data

| 英文术语 | 中文 | 一句话解释 |
|---------|------|-----------|
| **Data Item** | 数据项 | 节点之间传递的基本数据单元 |
| **JSON** | JSON 数据 | 一种通用的结构化文本数据格式（后面详细讲） |
| **$json** | 当前数据引用 | 表达式里代表「当前节点收到的数据」 |
| **Mapping / Drag & Drop** | 数据映射 | 把上一节点的字段拖拽到参数框里自动生成表达式 |
| **Pinning (Data Pinning)** | 数据固定 | 开发时把某节点的输出固定住，方便测试（正式运行时自动忽略） |

### 3.3 逻辑与流程 / Logic & Flow

| 英文术语 | 中文 | 一句话解释 |
|---------|------|-----------|
| **If Node** | 条件判断节点 | 满足条件走「真」分支，否则走「假」分支 |
| **Switch Node** | 分支选择节点 | 按多个条件把数据分流到不同分支 |
| **Merge Node** | 合并节点 | 把多条数据合并成一条 |
| **Loop** | 循环 | 对一批数据逐条处理 |
| **Wait Node** | 等待节点 | 让工作流暂停一段时间或等到某个时间点 |
| **Error Trigger** | 错误触发器 | 工作流出错时触发另一个工作流来处理错误 |

### 3.4 AI 相关（了解即可）/ AI Terms

| 英文术语 | 中文 | 一句话解释 |
|---------|------|-----------|
| **AI Agent** | AI 代理 | 能自主决策、调用工具完成任务的 AI 系统 |
| **LLM (Large Language Model)** | 大语言模型 | 像 GPT 这类 AI 模型，理解和生成文字 |
| **RAG** | 检索增强生成 | 让 AI 从你自己的资料库里查找信息再回答 |
| **Embedding / Vector Store** | 向量化 / 向量库 | 把文字变成数学向量，用于让 AI 检索资料 |

### 3.5 部署与计划 / Deployment & Plans

| 英文术语 | 中文 | 一句话解释 |
|---------|------|-----------|
| **n8n Cloud** | n8n 云服务 | 官方托管的云版本，免安装 |
| **Self-hosted** | 自部署 | 安装在自己服务器/电脑上的版本 |
| **Community Edition** | 社区版 | 免费版本，几乎包含全部功能 |
| **Business / Enterprise** | 商业版 / 企业版 | 付费版本，解锁高级功能（SSO、项目等） |
