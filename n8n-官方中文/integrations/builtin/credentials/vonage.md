# Vonage 凭证

> **大白话**：Vonage 是短信/语音 API 服务商。登录开发者后台，到「用户账户 > 设置 > API 设置」里把 API Key 和 API Secret 复制出来填进 n8n 就行。

你可以使用这些凭证对以下节点进行身份验证：

- [Vonage](../app-nodes/n8n-nodes-base.vonage.md)

## 前置条件

创建一个 [Vonage 开发者](https://developer.vonage.com)账户。

## 支持的认证方式

- API key（API 密钥）

## 相关资源

更多关于该服务的信息，请参考 [Vonage 的 SMS API 文档](https://developer.vonage.com/en/api/sms)。

## 使用 API key

要配置此凭证，你需要：

- **API Key**
- **API Secret**

从你的[开发者控制台](https://dashboard.nexmo.com/)的 **user account > Settings > API Settings**（用户账户 > 设置 > API 设置）中获取 **API Key** 和 **API Secret**。更多信息请参考 [Retrieve your account information](https://developer.vonage.com/en/account/guides/dashboard-management#retrieve-your-account-information)。
