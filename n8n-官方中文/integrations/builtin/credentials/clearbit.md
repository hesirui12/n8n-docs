# Clearbit 凭证

> **大白话**：Clearbit 是查询企业信息的服务（比如根据邮箱/域名查出公司资料）。想让 n8n 用它，就去 Clearbit 后台申请一把 API Key（钥匙），填进 n8n 的凭证里就行。

这些凭证可以用来验证以下节点的身份：

- [Clearbit](../app-nodes/n8n-nodes-base.clearbit.md)

## 准备工作（Prerequisites）

先注册一个 [Clearbit](https://www.clearbit.com/) 账号。

## 支持的验证方式（Supported authentication methods）

- API key（API 密钥）

## 相关资源（Related resources）

关于如何使用该服务进行身份验证，请参考 [Clearbit 的 API 文档](https://dashboard.clearbit.com/docs)。

## 使用 API key（API 密钥）

要配置这个凭证，你需要准备：

- **API Key（API 密钥）**：关于如何创建和查看 API 密钥，请参考 [Clearbit 的 API 认证文档](https://dashboard.clearbit.com/docs#authentication)。
