# Humantic AI 凭证

{% hint style="info" %}
**大白话**：Humantic AI 是一个「读懂人」的 AI 服务——通过公开信息分析一个人的人格画像（用在销售、招聘等场景）。n8n 连它很简单，只需要一把 **API Key（API 密钥）**。到它的 API 页面申请（也提供免费试用），填进 n8n 就行。
{% endhint %}

这些凭证可以用来验证以下节点的身份：

- [Humantic AI](../app-nodes/n8n-nodes-base.humanticai.md)

## 前提条件

创建一个 [Humantic AI](https://humantic.ai/) 账号。

你也可以在 [Humantic AI API](https://api.humantic.ai/) 页面免费试用一个 API key。

## 支持的验证方式

- API key（API 密钥）

## 相关资源

关于该服务的更多信息，请参考 [Humantic AI 的 API 文档](https://api.humantic.ai)。

## 使用 API key（API 密钥）

要配置这个凭证，你需要：

- 一个 **API Key（API 密钥）**：从 [Humantic AI API](https://api.humantic.ai/) 页面获取。
