# SolarWinds Observability SaaS 凭证

> **大白话**：SolarWinds Observability 是 SolarWinds 出品的云监控平台（SaaS 版），用来监控服务器、应用和云资源。这篇文档教你怎么在 n8n 里配置凭证：填上平台网址 + 在「Settings > Api Tokens」里生成的 API 令牌就行。

{% include "https://app.gitbook.com/s/GixZThfitWP21x2gQFpD/~/reusable/7QbEnpnpOks3Rq0SiMFb/" %}

## 支持的认证方式

* API Token（API 令牌）

## 相关资源

关于该服务的更多信息，请参阅 [SolarWinds Observability SaaS 的 API 文档](https://documentation.solarwinds.com/en/success_center/observability/content/api/api-swagger.htm)。


## 使用 API Token（API 令牌）

要配置此凭证，你需要一个 SolarWinds Observability SaaS 账号，以及：

- **URL（网址）**：你用来访问 SolarWinds Observability SaaS 平台的网址
- **API Token（API 令牌）**：在 SolarWinds Observability SaaS 平台的 **Settings（设置）> Api Tokens（API 令牌）** 下找到的 API 令牌

关于如何向该服务进行认证的更多信息，请参阅 [SolarWinds Observability SaaS 的 API 文档](https://documentation.solarwinds.com/en/success_center/observability/content/settings/api-tokens.htm)。
