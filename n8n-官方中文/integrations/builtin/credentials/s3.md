# S3 凭证

{% hint style="info" %}
**大白话**：S3 是「对象存储」的标准协议，AWS S3 用它，很多第三方存储（DigitalOcean Spaces、MinIO、Tigris、Wasabi 等）也都兼容它。n8n 连 S3 填五样：**S3 Endpoint（存储地址）**、**Region（区域）**、**Access Key ID（访问密钥 ID）**、**Secret Access Key（密钥）**，加上两个可选开关（Force Path Style、Ignore SSL Issues）。后面还有三家主流服务商（DigitalOcean、Tigris、Wasabi）的详细填法，照着抄就行。
{% endhint %}

这些凭证可以用来验证以下节点的身份：

- [S3](../app-nodes/n8n-nodes-base.s3.md)

## 准备工作

在一台兼容 S3 的服务器上创建一个账号。使用 S3 节点连接通用的或非 AWS 的 S3 服务，比如：

* [DigitalOcean Spaces](https://www.digitalocean.com/products/spaces)
* [MinIO](https://min.io/)
* [Tigris](https://www.tigrisdata.com/)
* [Wasabi](https://wasabi.com/)

## 支持的验证方式

- S3 endpoint（S3 端点）

## 相关资源

关于该服务的更多信息，请参考你的 S3 兼容服务商的文档。例如 [Wasabi 的 REST API 文档](https://docs.wasabi.com/docs/rest-api-introduction) 或 [DigitalOcean 的 Spaces API 参考文档](https://docs.digitalocean.com/reference/api/spaces-api/)。

## 使用 S3 endpoint（S3 端点）

要配置这个凭证，你需要准备：

- **S3 Endpoint（S3 端点）**：输入 S3 存储后端的 URL 端点地址。
- **Region（区域）**：输入你的 S3 存储所在的区域。有些服务商把它叫做「region slug（区域标识）」，即区域代号。
- **Access Key ID（访问密钥 ID）**：输入你的 S3 服务商用来访问存储桶（bucket）或空间（space）的访问密钥。有些服务商把它叫做 API keys（API 密钥）。
- **Secret Access Key（密钥）**：输入与 **Access Key ID** 对应的秘密访问密钥。
- **Force Path Style（强制路径风格）**：打开后，连接对存储桶使用路径风格（path-style）寻址。
- **Ignore SSL Issues（忽略 SSL 问题）**：打开后，即使 SSL 证书校验失败，n8n 也会继续连接。

下面针对 DigitalOcean Spaces、Tigris 和 Wasabi 给出更详细的说明。如果你用的是其他服务商，请参考他们的文档。

### 使用 DigitalOcean Spaces

要为 DigitalOcean Spaces 配置凭证：

1. 在 DigitalOcean 中，进入控制面板并打开 **Settings（设置）**。你的端点（endpoint）应该列在那里。在该端点前加上 `https://`，作为 n8n 里的 **S3 Endpoint** 填入。
    - 你的 DigitalOcean 端点取决于你的存储桶所在的数据中心区域。
2. 在 **Region（区域）** 里，输入你的存储桶所在的区域，比如 `nyc3`。
    - 如果你打算用这个凭证创建新的 Spaces，请改填 `us-east-1`。
3. 从你的 DigitalOcean 控制面板前往 [**API**](https://cloud.digitalocean.com/account/api/spaces)。
4. 打开 **Spaces Keys** 标签页。
5. 选择 **Generate New Key（生成新密钥）**。
6. 为你的密钥输入一个 **Name（名称）**，比如 `n8n integration`，然后勾选确认。
7. 复制名称旁边显示的 **Key（密钥）**，作为 n8n 的 **Access Key ID** 填入。
8. 复制 **Secret** 值，作为 n8n 的 **Secret Access Key** 填入。
    - 关于生成密钥和 secret 的更多说明，请参考[使用访问密钥共享存储桶访问权限](https://docs.digitalocean.com/products/spaces/how-to/manage-access/#access-keys)文档。
9. 保持 **Force Path Style** 开关关闭，除非你想使用子域名/虚拟主机（virtual calling）格式。
10. 决定 n8n 凭证如何处理 SSL：
    - 要遵守 SSL 证书校验，保持 **Ignore SSL Issues** 默认关闭。
    - 要即使 SSL 证书校验失败也继续连接，打开 **Ignore SSL Issues**。

更多说明请参考 DigitalOcean 的 [Spaces API 参考文档](https://docs.digitalocean.com/reference/api/spaces-api/)。

### 使用 Tigris

要为 Tigris 配置凭证：

1. 在 **S3 Endpoint** 里输入 `https://t3.storage.dev`。
    - Tigris 使用一个全局端点，没有区域选择——数据从离请求最近的区域提供。
2. 在 **Region（区域）** 里输入 `auto`。
    - 该值用于 SigV4 请求签名，是必填的，但 Tigris 服务本身会忽略它。
3. 登录 [Tigris Console（控制台）](https://console.storage.dev/)。
4. 从侧边栏选择 **Access Keys（访问密钥）**。
5. 在右上角选择 **Create New Access Key（创建新访问密钥）**。
6. 为密钥输入一个 **Name（名称）**，比如 `n8n integration`，然后选择 **Create（创建）**。
7. 复制显示的 **Access Key ID**（以 `tid_` 开头），作为 n8n 的 **Access Key ID** 填入。
8. 复制显示的 **Secret Access Key**（以 `tsec_` 开头），作为 n8n 的 **Secret Access Key** 填入。
    - secret 只显示一次。如果弄丢了，你需要创建一个新密钥。
9. 保持 **Force Path Style** 开关关闭。Tigris 使用虚拟主机风格（virtual-hosted-style）寻址。
10. 决定 n8n 凭证如何处理 SSL：
    - 要遵守 SSL 证书校验，保持 **Ignore SSL Issues** 默认关闭。
    - 要即使 SSL 证书校验失败也继续连接，打开 **Ignore SSL Issues**。

更多说明请参考 Tigris 的[管理访问密钥文档](https://www.tigrisdata.com/docs/iam/manage-access-key/)。

### 使用 Wasabi

要为 Wasabi 配置凭证：

1. 在 **S3 Endpoint** 里输入你存储桶所在区域的服务 URL。以 `https://` 开头。
    - 请参考 [Wasabi 存储区域的服务 URL](https://docs.wasabi.com/v1/docs/service-urls-for-wasabis-storage-regions) 确定正确的 URL。
2. 在 **Region（区域）** 里输入服务 URL 中的区域代号部分。例如，如果你在 **S3 Endpoint** 里填了 `https://s3.us-east-2.wasabisys.com`，那么 `us-east-2` 就是区域。
3. 以 root 用户身份登录你的 Wasabi 控制台。
4. 打开 **Menu（菜单）** 并选择 **Access Keys（访问密钥）**。
5. 选择 **CREATE NEW ACCESS KEY（创建新访问密钥）**。
6. 选择密钥是给 **Root User（根用户）** 还是 **Sub-User（子用户）** 使用，然后选择 **CREATE（创建）**。
7. 复制 **Access Key**，作为 n8n 的 **Access Key ID** 填入。
8. 复制 **Secret Key**，作为 n8n 的 **Secret Access Key** 填入。
    - 关于生成密钥和 secret 的更多说明，请参考[创建新访问密钥](https://docs.wasabi.com/v1/docs/creating-a-new-access-key)文档。
9. Wasabi 建议打开 **Force Path Style** 开关，因为「路径风格在存储桶命名上提供最大的灵活性，可以避免域名问题」。更多说明请参考 Wasabi 的 [REST API 简介](https://docs.wasabi.com/docs/rest-api-introduction)。
10. 决定 n8n 凭证如何处理 SSL：
    - 要遵守 SSL 证书校验，保持 **Ignore SSL Issues** 默认关闭。
    - 要即使 SSL 证书校验失败也继续连接，打开 **Ignore SSL Issues**。
