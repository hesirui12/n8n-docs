# SolarWinds IPAM 凭证

> **大白话**：SolarWinds IPAM 是 IT 运维领域的「IP 地址管理工具」，用来统一管理公司网络里的 IP 地址、子网和 DNS。这篇文档教你怎么在 n8n 里配置凭证：填上服务器网址 + 登录用户名密码就行了。

{% include "https://app.gitbook.com/s/GixZThfitWP21x2gQFpD/~/reusable/7QbEnpnpOks3Rq0SiMFb/" %}

## 支持的认证方式

* 用户名和密码（Username & Password）

## 相关资源

关于该服务的更多信息，请参阅 [SolarWinds IPAM 的 API 文档](https://github.com/solarwinds/OrionSDK/wiki/REST)。

## 使用用户名和密码

要配置此凭证，你需要一个 SolarWinds IPAM 账号，以及：

- **URL（网址）**：你的 SolarWinds IPAM 服务器的基础网址
- **Username（用户名）**：你用来访问 SolarWinds IPAM 的用户名
- **Password（密码）**：你用来访问 SolarWinds IPAM 的密码

关于如何向该服务进行认证的更多信息，请参阅 [SolarWinds IPAM 的 API 文档](https://github.com/solarwinds/OrionSDK/wiki/REST)。
