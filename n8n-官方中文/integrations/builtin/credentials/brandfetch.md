# Brandfetch 凭证

> 大白话：Brandfetch 是一个「查品牌资料」的工具，能自动拿到某个品牌的 Logo、颜色、字体等素材。n8n 想用它的接口，只需要你去注册一个开发者账号，拿到一把 API Key（钥匙）填进 n8n 就行。

这些凭证可以用来验证以下节点的身份：

- [Brandfetch](../app-nodes/n8n-nodes-base.brandfetch.md)

## 准备工作

注册一个 [Brandfetch 开发者账号](https://docs.brandfetch.com/docs/apis#-create-an-account)。

## 支持的验证方式

- API key（API 密钥）

## 相关资源

关于该服务的更多信息，请参考 [Brandfetch 官方 API 文档](https://docs.brandfetch.com/docs/apis)。

## 使用 API key（API 密钥）

要配置这个凭证，你需要准备：

- 一个 **API Key（API 密钥）**：如何生成，请参考 [Brandfetch 创建账号文档](https://docs.brandfetch.com/docs/apis#-create-an-account)。
