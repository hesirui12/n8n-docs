# UpLead 凭证

> **大白话**：UpLead 是找企业客户线索的平台。登录后到「账户 > 个人资料」里点一下生成新的 API Key，复制到 n8n 就行，很简单。

你可以使用这些凭证对以下节点进行身份验证：

- [UpLead](../app-nodes/n8n-nodes-base.uplead.md)

## 前置条件

创建一个 [UpLead](https://uplead.com/) 账户。

## 支持的认证方式

- API key（API 密钥）

## 相关资源

更多关于该服务的信息，请参考 [UpLead 的 API 文档](https://docs.uplead.com/#overview)。

## 使用 API key

要配置此凭证，你需要：

- **API Key**：前往你的 **Account > Profiles**（账户 > 个人资料）选择 **Generate New API Key**（生成新的 API 密钥）。
