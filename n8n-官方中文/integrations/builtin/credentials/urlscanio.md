# urlscan.io 凭证

> **大白话**：urlscan.io 是在线网址安全扫描服务。注册账号后，去「设置与 API > API 密钥」页面把 API Key 复制出来填进 n8n 就行。

你可以使用这些凭证对以下节点进行身份验证：

- [urlscan.io](../app-nodes/n8n-nodes-base.urlscanio.md)

## 前置条件

创建一个 [urlscan.io](https://urlscan.io/) 账户。

## 支持的认证方式

- API key（API 密钥）

## 相关资源

更多关于该服务的信息，请参考 [urlscan.io 的 API 文档](https://urlscan.io/docs/api/)。

## 使用 API key

要配置此凭证，你需要：

- **API Key**：从 **Settings & API > API Keys**（设置与 API > API 密钥）获取你的 API key。
