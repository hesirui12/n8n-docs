# Tapfiliate 凭证

{% hint style="info" %}
**大白话**：Tapfiliate 是联盟营销/推广追踪平台（管理你的推广链接和佣金分成）。n8n 连它很简单：去你的**个人资料设置**里复制 **API Key（API 密钥）**，填进来就行。
{% endhint %}

这些凭证可以用来验证以下节点的身份：

- [Tapfiliate](../app-nodes/n8n-nodes-base.tapfiliate.md)

## 先决条件

注册一个 [Tapfiliate](https://tapfiliate.com/) 账号。

## 支持的验证方式

- API key（API 密钥）

## 相关资源

关于该服务的更多信息，请参考 [Tapfiliate 官方 API 文档](https://tapfiliate.com/docs/rest/)。

## 使用 API key（API 密钥）

要配置这个凭证，你需要：

- 一个 **API Key（API 密钥）**：从你的 [**Profile Settings（个人资料设置）**](https://app.tapfiliate.com/a/profile/) **> API Key（API 密钥）** 获取。

更多信息请参考[你的 API 密钥](https://support.tapfiliate.com/en/articles/1441950-your-api-key)。
