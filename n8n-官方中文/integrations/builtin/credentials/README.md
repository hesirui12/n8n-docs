# 凭证库（Credentials）

{% hint style="info" %}
**大白话**：这一页是整个「凭证（Credentials）」部分的目录说明。所谓凭证，就是 n8n 用来验证身份的「钥匙」——每个节点想接入外部服务（某个软件、数据库、API）时，都要先在 n8n 里把对应的钥匙配置好。这一整节就是教你怎么拿到这些钥匙、填到哪里。
{% endhint %}

本部分包含 n8n 中各种节点身份验证的逐步说明（一步一步教你怎么配）。
