# Dropcontact 凭证（Dropcontact credentials）

> **大白话**：Dropcontact 是一个「数据补全」服务——你给它一个邮箱，它帮你补充对应的人名、职位、公司等信息（常用于销售找客户线索）。n8n 连它只需要一个 **API Key**，在 Dropcontact 网站的 **API** 页面就能看到。

你可以使用这些凭证来认证以下节点：

- [Dropcontact](../app-nodes/n8n-nodes-base.dropcontact.md)

## 前置条件（Prerequisites）

在 [Dropcontact](https://app.dropcontact.com/signup) 创建一个开发者账号。

## 支持的认证方式（Supported authentication methods）

- API key

## 相关资源（Related resources）

更多关于该服务的信息，请参考 [Dropcontact 的 API 文档](https://developer.dropcontact.com/)。

## 使用 API key（Using API key）

要配置这个凭证，你需要：

- 一个 **API Key**：要在 Dropcontact 中查看你的 API key，请前往 [**API**](https://app.dropcontact.com/api) 页面。更多信息请参考 [Dropcontact API key 文档](https://support.dropcontact.com/article/237-how-to-use-the-dropcontact-api-key)。
