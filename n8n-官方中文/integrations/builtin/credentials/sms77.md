# seven 凭证

> **大白话**：seven（原名 SMS77）是一个发短信、语音电话、WhatsApp 消息的服务商。这篇文档教你怎么在 n8n 里填 API 密钥，让 n8n 能通过它发短信或打电话。

你可以使用这些凭证来验证以下节点：

- [seven](../app-nodes/n8n-nodes-base.sms77.md)

## 前置条件

创建一个 [seven](https://www.seven.io/en) 开发者账号。

## 支持的认证方式

- API key（API 密钥）

## 相关资源

关于该服务的更多信息，请参阅 [seven 的 API 文档](https://docs.seven.io/en)。

## 使用 API key（API 密钥）

要配置此凭证，你需要准备：

- **API key（API 密钥）**：前往 **Account（账号）> Developer（开发者）>** [**API Keys（API 密钥）**](https://app.seven.io/developer#create-api-key) 创建 API 密钥。更多信息请参阅 [API 第一步](https://docs.seven.io/en/rest-api/first-steps)。
