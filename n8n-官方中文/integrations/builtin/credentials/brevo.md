# Brevo 凭证

> 大白话：Brevo 是发营销邮件/短信的工具（以前叫 Sendinblue）。n8n 想帮你自动发邮件、管联系人，只需要你去 Brevo 开发者后台建一把 API Key（钥匙）填进 n8n 就行。

这些凭证可以用来验证以下节点的身份：

* [Brevo 节点](../app-nodes/n8n-nodes-base.brevo.md)
* [Brevo Trigger 触发器节点](../trigger-nodes/n8n-nodes-base.brevotrigger.md)

## 准备工作

注册一个 [Brevo](https://www.brevo.com/) 开发者账号。

## 支持的验证方式

- API key（API 密钥）

## 相关资源

关于该服务身份验证的更多信息，请参考 [Brevo 官方 API 文档](https://developers.brevo.com/reference/getting-started-1)。

## API key（API 密钥）

要配置这个凭证，你需要准备：

- 一个 **API Key（API 密钥）**：如何创建，请参考 [Brevo API 快速入门文档](https://developers.brevo.com/docs/getting-started#quick-start)。
