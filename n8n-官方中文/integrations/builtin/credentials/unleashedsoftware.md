# Unleashed Software 凭证

> **大白话**：Unleashed Software 是库存管理软件。去后台的 API 访问设置里把 API ID 和 API Key 复制出来填进 n8n 就行。注意：必须用账户所有者（老板账号）登录才能看到这两个值。

你可以使用这些凭证对以下节点进行身份验证：

- [Unleashed Software](../app-nodes/n8n-nodes-base.unleashedsoftware.md)

## 前置条件

创建一个 [Unleashed Software](https://www.unleashedsoftware.com/) 账户。

## 支持的认证方式

- API key（API 密钥）

## 相关资源

更多关于该服务的信息，请参考 [Unleashed 的 API 文档](https://apidocs.unleashedsoftware.com/)。

## 使用 API key

要配置此凭证，你需要：

- **API ID**：前往 **Integrations > Unleashed API Access**（集成 > Unleashed API 访问）查找你的 **API ID**。
- **API Key**：前往 **Integrations > Unleashed API Access**（集成 > Unleashed API 访问）查找你的 **API Key**。

更多信息请参考 [Unleashed API Access](https://support.unleashedsoftware.com/hc/en-us/articles/4402393233689-Unleashed-API-Access)。

{% hint style="info" %}
**需要账户所有者**

你必须以 Unleashed 账户所有者的身份登录，才能查看 API ID 和 API Key。
{% endhint %}
