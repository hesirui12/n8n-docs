# Mailchimp Trigger 节点

> **大白话**：Mailchimp 是一款综合营销平台，商家可以自动发送邮件营销活动并追踪用户参与度。这个触发器节点监听 Mailchimp 里的动态——比如有人订阅了你的邮件列表、退订了、点开了邮件等等——一有动静就启动你的工作流。

[Mailchimp](https://mailchimp.com/) 是一款综合营销平台，允许商家自动化邮件营销活动并追踪用户参与度。
