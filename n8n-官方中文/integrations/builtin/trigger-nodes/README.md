# 触发器库（Triggers library）

> **大白话**：这一节是 n8n 所有「触发器节点」的目录。触发器节点就是工作流的「启动开关」——没有它，工作流就不知道什么时候该运行。每个正式使用的工作流至少要有一个触发器。

本节提供关于 [n8n 的触发器（Triggers）](#user-content-fn-1)[^1] 的信息。

[^1]: 触发器节点是一种特殊节点，负责在满足特定条件时执行工作流。所有用于生产环境的工作流至少需要一个触发器，用来决定工作流什么时候运行。
