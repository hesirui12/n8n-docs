# Mautic Trigger 节点

> **大白话**：Mautic 是一款开源的营销自动化软件，能帮你自动化重复性营销工作：潜在客户获取、联系人评分、联系人分组、营销活动等。这个触发器节点监听 Mautic 里的动态，一有动静就启动你的工作流。

[Mautic](https://www.mautic.org/) 是一款开源营销自动化软件，帮助在线企业自动化重复性营销任务，例如潜在客户获取、联系人评分、联系人分组和营销活动。
