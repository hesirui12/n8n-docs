# Eventbrite 触发器节点（Eventbrite Trigger node）

{% hint style="info" %}
**大白话**：Eventbrite 是一个活动管理和售票网站，用户可以浏览、创建和推广本地活动（如演唱会、课程、会议），还能在线售票。这个触发器节点会在活动相关事件发生时自动唤醒你的工作流（比如有人买票、活动被创建等）。用法：把节点放工作流开头，授权 Eventbrite 账号，之后对应事件一发生就会自动触发后续流程。
{% endhint %}

[Eventbrite](https://www.eventbrite.com/) 是一个活动管理和售票网站。该服务允许用户浏览、创建和推广本地活动。
