# LoneScale Trigger 节点

> **大白话**：LoneScale 是一个让工作流（workflow）可以互相连接、还能和人协作的工具。这个触发器节点的作用：只要 LoneScale 那边有新的工作流事件发生，就启动你的 n8n 工作流，把事件数据送进来。

使用 LoneScale Trigger 节点来响应 [LoneScale](https://www.lonescale.com/) 中的工作流事件，并将 LoneScale 与其他应用程序集成。

本页面列出了 LoneScale 节点支持的操作，以及更多资源的链接。
