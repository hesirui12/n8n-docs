# Jira Trigger 节点

> **大白话**：Jira 是 Atlassian 出品的付费问题跟踪工具，主要用于 bug 跟踪和敏捷项目管理。这个触发器节点监听 Jira 里的动态（比如有人创建了新工单、工单状态变了），一有动静就启动你的工作流去自动处理。

[Jira](https://www.atlassian.com/software/jira) 是 Atlassian 开发的专有问题跟踪产品，支持 bug 跟踪和敏捷项目管理。
