# Pipedrive 触发器节点

> **大白话**：这个节点是 Pipedrive 销售系统的「雷达站」。当你的销售管道里发生"新建了商机、客户信息被改了、交易成交了"这类事件时，它就启动你的工作流，自动帮你跟进、通知销售、更新其他系统。放在工作流开头使用。

[Pipedrive](https://www.pipedrive.com/) 是一家基于云的销售软件公司，旨在通过他们的软件帮助企业提升工作效率。

{% hint style="info" %}
**凭据（Credentials）**

你可以[在此处](../credentials/pipedrive.md)找到此节点的身份验证信息。
{% endhint %}

**示例和模板（Examples and templates）**

想查看使用示例和模板来快速上手，请访问 n8n 的 [Pipedrive Trigger integrations](https://n8n.io/integrations/pipedrive-trigger/) 页面。
{% endhint %}
