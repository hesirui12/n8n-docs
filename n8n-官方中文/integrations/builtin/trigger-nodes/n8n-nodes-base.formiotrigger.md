# Form.io 触发器节点

> **大白话**：Form.io 是"表单 + API 数据管理"二合一的企业级平台，用来做复杂的表单业务应用。这个触发器节点就是监听 Form.io 里发生的各种事件（比如表单被提交），然后触发工作流。

[Form.io](https://www.form.io/) 是一个企业级的表单与 API 数据管理组合平台，用于构建基于表单的复杂业务流程应用。
