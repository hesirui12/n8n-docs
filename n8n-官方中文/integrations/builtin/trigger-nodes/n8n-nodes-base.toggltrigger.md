# Toggl 触发器节点

> **大白话**：这个节点是 Toggl 计时工具的「事件播报员」。当你的 Toggl 里发生"开始计时、停止计时、新建了项目"等事件时，它就启动你的工作流，方便你自动记录工时、生成报表。放在工作流开头使用。

[Toggl](https://toggl.com/) 是一个时间跟踪应用，通过网站以及移动和桌面应用提供在线计时和报告服务。

{% hint style="info" %}
**凭据（Credentials）**

你可以[在此处](../credentials/toggl.md)找到此节点的身份验证信息。
{% endhint %}

想查看使用示例和模板来快速上手，请访问 n8n 的 [Toggl Trigger integrations](https://n8n.io/integrations/toggl-trigger/) 页面。
{% endhint %}
