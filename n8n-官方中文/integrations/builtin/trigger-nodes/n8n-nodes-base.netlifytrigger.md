# Netlify Trigger 节点

> **大白话**：Netlify 是一个网站托管 + Serverless 后端服务平台，适合部署静态网站和 Web 应用。这个触发器节点监听 Netlify 里的动态——比如有人往你的网站仓库推送了代码、部署完成——一有动静就启动你的工作流。

[Netlify](https://netlify.com/) 为 Web 应用和静态网站提供托管和无服务器（serverless）后端服务。
