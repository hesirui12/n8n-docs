# Typeform 触发器节点

> **大白话**：Typeform 是个做在线表单和问卷调查的网站工具，能根据你的需要做出各种动态表单。这个触发器节点的作用就是：每当有人提交了你的 Typeform 表单，就立刻启动你的 n8n 工作流，把提交的数据送进来处理。

[Typeform](https://www.typeform.com/) 是一家在线软件即服务（SaaS）公司，专门提供在线表单构建和在线问卷调查服务。它的主要软件可以根据用户需求创建动态表单。
