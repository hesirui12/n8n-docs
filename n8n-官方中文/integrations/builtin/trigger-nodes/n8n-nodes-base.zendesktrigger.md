# Zendesk 触发器节点

> **大白话**：Zendesk 是个客服工单系统，用来跟踪、排序和解决客户支持问题。它不只是个帮助台，还能通过个性化、响应式的多通道支持来维护客户关系。这个触发器节点的作用是：当有新的客服工单或工单状态变化时，就自动启动 n8n 工作流，让你自动分配工单、发通知或做报表。

[Zendesk](https://www.zendesk.com/) 是一个客服工单系统，旨在帮助跟踪、优先处理和解决客户支持交互。Zendesk Support 不仅仅是一个帮助台，它还能通过任何渠道提供个性化、响应式的支持，帮助维护客户关系。
