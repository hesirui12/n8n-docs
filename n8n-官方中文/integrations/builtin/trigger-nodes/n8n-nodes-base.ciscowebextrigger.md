# Webex by Cisco 触发器节点（Webex by Cisco Trigger node）

{% hint style="info" %}
**大白话**：Webex（思科出品）是一款视频会议/网络会议软件，常用于远程开会、在线培训。这个触发器节点会在 Webex 里发生相关事件（比如有新会议、收到新消息）时自动触发你的工作流。用法：把节点放工作流开头，授权你的 Webex 账号，之后相关事件一发生就会自动跑起来。
{% endhint %}

[Webex by Cisco](https://webex.com/) 是一款网络会议和视频会议应用。
