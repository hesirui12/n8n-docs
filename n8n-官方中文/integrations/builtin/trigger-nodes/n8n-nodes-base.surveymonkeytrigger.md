# SurveyMonkey 触发器节点

> **大白话**：这个节点是问卷调查的「答卷提示铃」。当有人提交了你的 SurveyMonkey 问卷时，它就启动你的工作流，让你自动处理新答卷——比如发感谢邮件、汇总数据、通知团队。放在工作流开头使用。

[SurveyMonkey](https://www.surveymonkey.com/) 是一个基于云的在线问卷 SaaS 平台，同时还提供一套付费的后台程序。

{% hint style="info" %}
**凭据（Credentials）**

你可以[在此处](../credentials/surveymonkey.md)找到此节点的身份验证信息。
{% endhint %}

**示例和模板（Examples and templates）**

想查看使用示例和模板来快速上手，请访问 n8n 的 [SurveyMonkey Trigger integrations](https://n8n.io/integrations/surveymonkey-trigger/) 页面。
{% endhint %}
