# Gumroad Trigger 节点

> **大白话**：Gumroad 是一个让创作者直接向消费者卖货（数字产品）的平台。这个触发器节点的作用是：一旦你的 Gumroad 商店有动静（比如有人买了东西），就自动启动你的 n8n 工作流去处理后续动作。

[Gumroad](https://gumroad.com) 是一个在线平台，让创作者能够直接向消费者销售产品。
