# Webflow 触发器节点

> **大白话**：Webflow 是一个不用写代码、靠浏览器里可视化编辑就能做出响应式网站的工具。这个触发器节点的作用是：当你的 Webflow 网站上发生事件（比如有人提交了表单、发布了新内容）时，就自动启动 n8n 工作流，把事件数据拿过来处理。

[Webflow](https://webflow.com) 是一个应用程序，让你可以通过基于浏览器的可视化编辑软件来构建响应式网站。
