# Mailjet Trigger 节点

> **大白话**：Mailjet 是一款云端的邮件发送与跟踪系统，既能发营销邮件也能发事务性邮件（比如验证码、订单通知），支持海量发送。这个触发器节点监听 Mailjet 里的邮件事件——比如邮件被打开、被点击、被退回——一有动静就启动你的工作流。

[Mailjet](https://www.mailjet.com/) 是一款基于云的邮件发送与跟踪系统。该平台让专业人员既能发送营销邮件，也能发送事务性邮件，并包含邮件设计、海量发送和邮件跟踪等工具。
