# Help Scout Trigger 节点

> **大白话**：Help Scout 是一款客服工单软件（支持邮件客服、知识库、可嵌入的搜索/联系小部件）。这个触发器节点负责监听 Help Scout 里发生的事件——比如收到新邮件、客户来咨询——一旦有动静就启动你的工作流，帮你自动回复、打标签、建工单等等。

[Help Scout](https://www.helpscout.com/) 是一款帮助台（help desk）软件，为客服专业人士提供基于电子邮件的客户支持平台、知识库工具，以及可嵌入的搜索/联系小部件。
