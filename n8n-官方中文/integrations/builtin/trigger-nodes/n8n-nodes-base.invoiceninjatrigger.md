# Invoice Ninja Trigger 节点

> **大白话**：Invoice Ninja 是一款免费开源的在线开票软件（自由职业者和公司都能用），能管开票、收款、报销和计时任务。这个触发器节点监听 Invoice Ninja 里的动作（比如收到一笔付款、开出一张新发票），一有动静就启动你的工作流。

[Invoice Ninja](https://www.invoiceninja.com/) 是一款面向自由职业者和企业的免费开源在线开票应用，提供开票、收款、费用跟踪和时间任务管理功能。
