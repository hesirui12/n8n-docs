# PayPal 触发器节点

> **大白话**：这个节点是 PayPal 的「收款播报员」。当你的 PayPal 账户发生支付、退款等事件时，它会收到通知并启动你的工作流，让你第一时间知道"谁付了钱"，然后自动去发货、记账、发邮件确认等。它是个触发器节点，放在工作流开头用。

[PayPal](https://paypal.com) 是一种数字支付服务，支持在线资金转账，顾客在网上购物时可以使用它。

{% hint style="info" %}
**凭据（Credentials）**

你可以[在此处](../credentials/paypal.md)找到此节点的身份验证信息。
{% endhint %}

**示例和模板（Examples and templates）**

想查看使用示例和模板来快速上手，请访问 n8n 的 [PayPal Trigger integrations](https://n8n.io/integrations/paypal-trigger/) 页面。
{% endhint %}
