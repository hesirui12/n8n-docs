# Taiga 触发器节点

> **大白话**：这个节点是 Taiga 项目管理平台的「事件广播员」。当项目里发生"新建了任务、改了需求、更新了用户故事"等事件时，它就启动你的工作流，方便你自动通知团队、同步数据。放在工作流开头使用。

[Taiga](https://www.taiga.io/) 是一个免费开源的项目管理平台，面向初创公司、敏捷开发者和设计师。

**凭据（Credentials）**

你可以[在此处](../credentials/taiga.md)找到此节点的身份验证信息。
