# Formstack 触发器节点

> **大白话**：Formstack 是一个"无代码办公"平台，专门做在线表单、文档和电子签名。这个触发器节点就是监听 Formstack 表单的提交事件，一有人提交表单就触发工作流。

[Formstack](https://www.formstack.com/) 是一个工作场所生产力平台，通过无代码的在线表单、文档和签名，帮助组织简化数字化工作。
