# Keap Trigger 节点

> **大白话**：Keap（就是以前的 Infusionsoft）是一个面向小企业的邮件营销和销售平台，管客户生命周期、CRM、营销自动化、潜在客户获取和电商。这个触发器节点监听 Keap 里的动态，一有动静就启动你的工作流。

[Keap](https://keap.com/) 是一个面向小企业的电子邮件营销和销售平台，提供管理并优化客户生命周期、客户关系管理（CRM）、营销自动化、潜在客户获取和电子商务的产品。
