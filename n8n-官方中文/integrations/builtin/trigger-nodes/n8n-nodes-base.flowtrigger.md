# Flow 触发器节点

> **大白话**：这个节点用来监听 Flow（一个团队任务/项目管理工具）里的新事件——比如有新任务、新动态产生时，自动触发你的工作流，让你第一时间处理。

[Flow](https://www.getflow.com/) 是一款现代化的团队任务和项目管理软件。它把任务、项目、时间线和对话整合在一起，并与很多工具集成。
