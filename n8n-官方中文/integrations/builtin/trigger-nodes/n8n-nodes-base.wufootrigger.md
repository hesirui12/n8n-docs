# Wufoo 触发器节点

> **大白话**：Wufoo 是个在线表单制作工具，不用写代码就能做出自定义的 HTML 表单。这个触发器节点的作用是：每当有人在你的 Wufoo 表单里提交内容时，就自动启动 n8n 工作流，把提交的数据抓进来处理。

[Wufoo](https://wufoo.com) 是一个在线表单构建工具，帮助你在不编写代码的情况下创建自定义的 HTML 表单。
