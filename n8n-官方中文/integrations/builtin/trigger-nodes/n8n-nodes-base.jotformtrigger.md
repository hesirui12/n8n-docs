# Jotform Trigger 节点

> **大白话**：Jotform 是一款在线表单制作服务，用拖拽就能做表单，还能对用户数据加密。这个触发器节点的作用：只要有人在你做的 Jotform 表单里提交了内容，它就立刻启动你的 n8n 工作流，把提交的数据送进去处理。

[Jotform](https://www.jotform.com/) 是一款在线表单制作服务。Jotform 的软件通过拖拽式创建工具制作表单，并支持对用户数据进行加密。
