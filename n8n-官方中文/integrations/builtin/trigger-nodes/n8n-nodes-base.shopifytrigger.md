# Shopify 触发器节点

> **大白话**：这个节点是网店的「成交报喜员」。当你的 Shopify 网店有新订单、商品被下单等事件发生时，它就启动你的工作流，自动去发货通知、记账、同步库存等。放在工作流开头使用。

[Shopify](https://www.shopify.com/) 是一个电商平台，让用户可以开设在线商店并销售产品。

{% hint style="info" %}
**凭据（Credentials）**

你可以[在此处](../credentials/shopify.md)找到此节点的身份验证信息。
{% endhint %}

{% hint style="info" %}
**示例和模板（Examples and templates）**

想查看使用示例和模板来快速上手，请访问 n8n 的 [Shopify Trigger integrations](https://n8n.io/integrations/shopify-trigger/) 页面。
{% endhint %}
