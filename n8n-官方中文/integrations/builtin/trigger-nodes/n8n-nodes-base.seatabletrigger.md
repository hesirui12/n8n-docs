# SeaTable 触发器节点

> **大白话**：这个节点是 SeaTable 表格数据库的「盯梢员」。当你的 SeaTable 表格/数据库里有数据发生变化时，它就会启动你的工作流去处理。适合做"表格新增了记录 → 自动通知/同步"这类自动化。

[SeaTable](https://seatable.com/) 是一个带电子表格界面的协作数据库应用。

{% hint style="info" %}
**凭据（Credentials）**

你可以[在此处](../credentials/seatable.md)找到此节点的身份验证信息。
{% endhint %}

{% hint style="info" %}
**示例和模板（Examples and templates）**

想查看使用示例和模板来快速上手，请访问 n8n 的 [SeaTable Trigger integrations](https://n8n.io/integrations/seatable-trigger/) 页面。
{% endhint %}
