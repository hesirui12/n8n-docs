# 子节点（Sub-nodes）

> **大白话**：这一页是"子节点"的导航目录。子节点就是挂在主节点（比如 AI Agent、LangChain Chain 这类"集群节点"）下面的小配件，用来给整个集群配置具体能力——比如选哪个大模型、用什么记忆、连什么向量库。你在画布上把子节点拖到主节点的接口上，主节点就"长"出了对应的功能。

子节点（Sub-nodes）挂载在集群节点（cluster nodes）组内的根节点（root nodes）上，用来配置整个集群的功能。
