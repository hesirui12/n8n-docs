# 空操作（No Operation, do nothing）

{% hint style="info" %}
**大白话（这个节点是干什么的）**：No Operation 节点是一个「什么都不做的占位符」：数据从它身上流过，它原样放行，不做任何处理。它的作用纯粹是让工作流的「画面」更清晰——比如某些数据流到这里就该结束了，放一个它，别人一眼就能看出「流程到此为止」，比让线条悬空更容易理解。
{% endhint %}

当你不想执行任何操作时，使用「空操作」（No Operation, do nothing）节点。这个节点的用途是让工作流更容易阅读，更容易理解数据流在哪里结束。这可以帮助其他人直观地更好地理解工作流。
