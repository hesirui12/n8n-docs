# 核心节点库（Core nodes library）

{% hint style="info" %}
**大白话**：这里是 n8n 核心节点的文档区。核心节点就是 n8n 自带的「通用工具型」节点——比如 HTTP Request（发 HTTP 请求）、Webhook（接收外部数据）、Schedule Trigger（定时触发）、Code（写代码）、If / Switch（条件判断与分流）等等。它们不连接某个具体 App，而是提供通用能力，是搭工作流最常用的零件。
{% endhint %}

本部分提供关于 n8n 核心节点[^1]的信息。

[^1]: 在 n8n 中，节点（nodes）是你组合起来创建工作流的各个独立组件。节点定义工作流何时运行，允许你获取、发送和处理数据，可以定义流程控制逻辑，并与外部服务连接。
