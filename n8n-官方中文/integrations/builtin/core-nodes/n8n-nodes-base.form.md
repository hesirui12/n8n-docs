# n8n Form 节点

> **大白话**：这个节点用来做"多步骤表单"的后续页面。比如第一页问了姓名，第二页可以接着问喜好。你可以在两页之间插入任意节点来处理用户上一页填的数据（比如判断条件、查数据库）。注意：工作流必须以 n8n Form Trigger 节点开头。

使用 n8n Form（表单）节点可以创建面向用户的多步骤表单。你可以把带有自定义逻辑的其他节点放在表单页之间，来处理用户的输入。工作流必须以 [n8n Form Trigger 节点](n8n-nodes-base.formtrigger.md) 开头。

## 设置节点

### 使用查询参数设置默认值

你可以使用 [n8n Form Trigger 节点](n8n-nodes-base.formtrigger.md) 提供的初始 URL 上的[查询参数（query parameters）](https://en.wikipedia.org/wiki/Query_string#Web_forms)来设置表单字段的初始值。发送到 n8n Form Trigger 节点 URL 的查询参数，表单中的每个页面都会收到相同的参数。

{% hint style="info" %}
**仅限生产环境**

查询参数只在表单使用生产模式时可用。在测试模式下，n8n 不会根据查询参数填充字段值。
{% endhint %}

使用查询参数时，请对包含特殊字符的字段名或值进行[百分号编码（percent-encode）](https://en.wikipedia.org/wiki/Percent-encoding)。这能确保 n8n 正确识别并使用给定字段的初始值。你可以使用 [URL Encode/Decode](https://www.url-encode-decode.com/) 之类的工具，用百分号编码来格式化你的查询参数。

举个例子，假设你有一个包含以下属性的表单：

* 生产 URL：`https://my-account.n8n.cloud/form/my-form`
* 字段：
	* `name`：`Jane Doe`
	* `email`：`jane.doe@example.com`

使用查询参数和百分号编码，你可以用下面的 URL 把上述数据设置为字段的初始值：

```
https://my-account.n8n.cloud/form/my-form?email=jane.doe%40example.com&name=Jane%20Doe
```

在这个例子中，百分号编码把 @ 符号（`@`）替换成字符串 `%40`，把空格字符（` `）替换成字符串 `%20`。这样，无论这些字段出现在表单的哪一页，都会被设置为上述初始值。

### 显示自定义 HTML

你可以在表单中添加一个 **Custom HTML（自定义 HTML）** 字段来显示自定义 HTML。它会提供一个 **HTML** 输入框，你可以在里面插入任意的 HTML 代码，作为表单页面的一部分展示。

你可以用这个 HTML 字段来丰富你的表单页面，比如加入链接、图片、视频等内容。n8n 会把这个内容与表单的其他字段一起，按照正常的文档流进行渲染。

因为自定义 HTML 内容是只读的，这些字段默认不会包含在表单的输出数据中。如果想把原始的 HTML 内容包含到节点输出中，请用 **Element Name（元素名称）** 字段为该数据提供一个名称。

HTML 字段不支持 `<script>`、`<style>` 或 `<input>` 元素。

如果你使用的是 **Form Ending（表单结束）** 页面类型，可以通过把 **On n8n Form Submission（n8n 表单提交时）** 参数设置为 **Show Text（显示文本）**，来完全自定义发送给用户的最终页面（包括使用 `<script>`、`<style>` 和 `<input>` 元素）。

### 包含隐藏字段

可以在表单中包含一些不向用户显示的字段。当你需要把不需要用户交互输入的额外数据传给表单时，这非常有用。

要添加不会在表单上显示的字段，请使用 **Hidden Field（隐藏字段）** 表单元素。在那里，你可以定义 **Field Name（字段名称）**，并可选地通过填写 **Field Value（字段值）** 来提供默认值。

在提供表单时，你可以使用[查询参数](#set-default-selections-with-query-parameters)为隐藏字段传值。

### 用 JSON 定义表单

使用 **Define Form（定义表单）** > **Using JSON（使用 JSON）** 可以用[JSON 对象数组](https://app.gitbook.com/s/rPN1zU5jaYNvwH7RzxqA/work-with-data/understand-n8ns-data-structure)来定义表单的字段。每个对象通过以下键的组合来定义单个字段：

- `fieldLabel`（字段标签）：渲染后表单中显示在输入框上方的标签。
- `fieldName`（字段名称）：用于 Form 节点输出以及在表达式中引用该字段的字段名。
- `fieldType`（字段类型）：从 `checkbox`（复选框）、`date`（日期）、`dropdown`（下拉框）、`email`（邮箱）、`file`（文件）、`hiddenField`（隐藏字段）、`html`（HTML）、`number`（数字）、`password`（密码）、`radio`（单选）、`text`（文本）或 `textarea`（多行文本）中选择。
    - 使用 `date` 可以在表单中包含日期选择器。关于日期格式化的更多信息，请参阅[使用 Luxon 处理日期和时间](https://app.gitbook.com/s/rPN1zU5jaYNvwH7RzxqA/work-with-data/handle-special-data-types/work-with-dates-and-times)。
	- 使用 `dropdown` 时，用 `fieldOptions` 设置选项（参考下面的示例）。默认情况下，下拉框是单选。如果想改为多选，把 `multiselect` 设为 `true`。另外，`checkbox` 或 `radio` 也可以配合 `fieldOptions` 使用。
	- 使用 `file` 时，把 `multipleFiles` 设为 `true` 可以允许用户选择多个文件。要定义允许的文件类型，把 `acceptFileTypes` 设为一个包含逗号分隔的文件扩展名列表的字符串（参考下面的示例）。
	- 使用 `hiddenField` 可以向表单添加隐藏字段。更多信息请参阅[包含隐藏字段](#including-hidden-fields)。
	- 使用 `html` 可以在表单中显示自定义 HTML。更多信息请参阅[显示自定义 HTML](#displaying-custom-html)。
- `placeholder`（占位符）：为字段指定占位符数据。除 `dropdown`、`checkbox`、`radio`、`date` 和 `file` 之外，所有 `fieldType` 都可以使用。
- `defaultValue`（默认值）：指定一个值，该值会在表单元素中预先填充或预先选中。除 `password`、`html`、`hiddenField` 和 `file` 之外，所有 `fieldType` 都可以使用。
- `requiredField`（必填字段）：要求用户在表单上完成此字段。

### 表单结束（Form Ending）

使用 **Form Ending（表单结束）** 页面类型来结束表单：可以显示一个完成页面、把用户重定向到一个 URL，或者显示自定义的 HTML 或文本。即使 n8n 执行了[多个分支](#forms-with-branches)并且这些分支里都有 Form Ending 节点，每次执行也只会显示一个 Form Ending 页面。

使用 **On n8n Form Submission（n8n 表单提交时）** 时，在以下选项中选择：

- **Show Completion Screen（显示完成页面）**：向用户显示一个最终页面，确认他们已提交表单。
	- 填写 **Completion Title（完成标题）** 来设置表单上的 `h1` 标题。
	- n8n 会把 **Completion Message（完成信息）** 显示为主 `h1` 标题下方的副标题。使用 `\n` 或 `<br>` 可以添加换行。
	- 选择 **Add option（添加选项）** 并填写 **Completion Page Title（完成页面标题）**，可以设置浏览器标签页中显示的页面标题。
- **Redirect to URL（重定向到 URL）**：表单完成时，把用户重定向到一个指定的 URL。
	- 在 **URL** 字段中填写用户完成表单后要重定向到的页面地址。
- **Show Text（显示文本）**：显示一个由任意纯文本和 HTML 定义的最终页面。
	- 在 **Text（文本）** 字段中填写你想要显示的 HTML 或纯文本内容。
- **Return Binary File（返回二进制文件）**：完成时返回一个二进制文件。
	- 填写 **Completion Title（完成标题）** 来设置表单上的 `h1` 标题。
	- n8n 会把 **Completion Message（完成信息）** 显示为主 `h1` 标题下方的副标题。使用 `\n` 或 `<br>` 可以添加换行。
	- 提供包含要返回给用户的二进制文件的 **Input Data Field Name（输入数据字段名称）**。

### 带分支的表单

n8n Form 节点只要从前一个节点收到数据，就会执行并显示它对应的表单页面。在用 n8n 构建表单时，理解发生分支时表单的行为非常重要，这样可以避免混淆。

#### 互斥分支的工作流

包含互斥分支（mutually exclusive branches）的表单工作流会按预期工作。n8n 会根据你提交的数据和设定的条件，只执行其中一条分支。执行过程中，n8n 会依次显示分支中的每个页面，最后以一个使用 **Form Ending（表单结束）** 页面类型的 n8n Form 节点结束。

#### 可能执行多个分支的工作流

同时向多个分支发送数据的表单工作流需要更加小心。当一次执行中多个分支都收到数据时（例如来自 [switch（切换）](n8n-nodes-base.switch.md) 节点的数据），n8n 会[按顺序](https://app.gitbook.com/s/rPN1zU5jaYNvwH7RzxqA/flow-logic/understand-execution-order)依次执行每个收到数据的分支。当一条分支执行到末尾时，执行会转到下一条有数据的分支。

n8n 每次执行只会执行一个 **Form Ending（表单结束）** 类型的 n8n Form 节点。当表单工作流的多个分支都收到数据时，n8n 会忽略除最后一条分支关联的那个 Form Ending 节点之外的所有 Form Ending 节点。

### 节点选项

选择 **Add Option（添加选项）** 可以查看更多配置选项：

- **Form Title（表单标题）**：表单的标题。n8n 会把 **Form Title** 显示为网页标题和表单上的主 `h1` 标题。
- **Form Description（表单描述）**：表单的描述。n8n 会把 **Form Description** 显示为主 `h1` 标题下方的副标题。此字段支持 HTML。使用 `\n` 或 `<br>` 可以添加换行。Form Description 还会填充页面的 [HTML meta description（元描述）](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/meta/name#standard_metadata_names_defined_in_the_html_specification)。
- **Button Label（按钮标签）**：用于表单提交按钮的标签。n8n 会把 **Button Label** 显示为提交按钮的名称。
- **Custom Form Styling（自定义表单样式）**：用 CSS 覆盖公开表单界面的默认样式。该字段会预先填入默认样式，所以你只需要修改需要改动的部分即可。
- **Completion Page Title（完成页面标题）**：表单最终完成页面的标题。

## 运行节点

### 构建和测试工作流

在构建或测试工作流时，请使用 [n8n Form Trigger 节点](n8n-nodes-base.formtrigger.md) 中的 **Test URL（测试 URL）**。使用测试 URL 可以确保你能在编辑器界面中看到传入的数据，这对于调试非常有用。

有两种测试方式：

- 选择 **Execute Step（执行当前节点）**。n8n 会打开表单。当你提交表单时，n8n 会运行当前节点以及它前面的节点，但不会运行工作流的其余部分。
- 选择 **Execute Workflow（执行整个工作流）**。n8n 会打开表单。当你提交表单时，n8n 会运行整个工作流。

### 生产环境工作流

当你的工作流准备好后，打开触发器节点，在 **From URLS（表单 URL）** 选择器中选择 **Production URL（生产 URL）**，切换到使用 n8n Form Trigger 的**生产 URL**。然后你就可以发布工作流，当用户提交表单时，n8n 会自动运行它。

在使用生产 URL 时，请确保你已经保存并发布了工作流。使用生产 URL 时，通过 Form Trigger 流动的数据不会显示在编辑器界面中。
