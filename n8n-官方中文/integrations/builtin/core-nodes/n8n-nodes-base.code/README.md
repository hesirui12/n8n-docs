# Code 节点

{% hint style="info" %}
**大白话**：Code（代码）节点让你直接在工作流里写 JavaScript 或 Python 代码。当内置节点做不了某些复杂的数据转换或逻辑时，就轮到它出场了——比如「把一堆数据按你的算法重新整理」「调用内置节点不支持的函数」等等。它就像一个「万能工具箱」，用代码来补上其他节点的短板。
{% endhint %}

Code 节点让你可以在工作流中运行自己的 JavaScript 或 Python 代码，从而转换数据或添加内置节点无法覆盖的逻辑。
