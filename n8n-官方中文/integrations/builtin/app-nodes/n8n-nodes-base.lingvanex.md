{% hint style="info" %}
**大白话**：LingvaNex 是一家提供翻译 API 的服务商（支持 100 多种语言）。这个节点功能很简单，就一件事：翻译数据（Translate data）。适合做「收到外文内容 → 自动翻译成中文 → 继续处理」这类流程。
{% endhint %}

# LingvaNex 节点

使用 LingvaNex 节点来自动化你在 LingvaNex 中的工作，并把它与其它应用集成。n8n 内置支持用 LingvaNex 翻译数据。

在本页你可以看到 LingvaNex 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [LingvaNex 凭证](../credentials/lingvanex.md)。
{% endhint %}

## 操作

- Translate data（翻译数据）
