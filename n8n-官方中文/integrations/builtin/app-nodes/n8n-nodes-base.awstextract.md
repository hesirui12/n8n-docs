# AWS Textract 节点

> 💡 **大白话**：AWS Textract 是亚马逊的「图片文字识别」服务，能自动从扫描件、发票、收据里读出文字和数字（比如金额、日期）。用这个节点，你可以在 n8n 里自动分析发票和收据，不用自己写代码。

使用 AWS Textract 节点自动化 AWS Textract 中的工作，并将 AWS Textract 与其他应用集成。n8n 内置支持大量 AWS Textract 功能，包括分析发票。

本页列出了 AWS Textract 节点支持的操作，以及更多资源链接。
