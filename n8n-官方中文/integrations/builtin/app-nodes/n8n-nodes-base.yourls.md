{% hint style="info" %}
**大白话**：Yourls 是一个「开源自建短链接服务」（Your Own URL Shortener）——你部署在自己的服务器上，用自己的域名做短链接。这个节点可以帮你：缩短长网址（Shorten）、把短链接还原成长网址（Expand）、查看某个短链接的统计信息（Get stats）。适合做自有品牌短链接、推广链接统计。
{% endhint %}

# Yourls 节点

使用 Yourls 节点来自动化你在 Yourls 中的工作，并把它与其它应用集成。n8n 内置支持 Yourls 的大量功能，包括展开和缩短 URL。

在本页你可以看到 Yourls 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Yourls 凭证](../credentials/yourls.md)。
{% endhint %}

## 操作

* URL（网址）
    * Expand a URL（展开 URL，还原长链接）
    * Shorten a URL（缩短 URL）
    * Get stats about one short URL（获取某个短链接的统计信息）
