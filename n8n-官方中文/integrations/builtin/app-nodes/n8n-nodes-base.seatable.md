{% hint style="info" %}
**大白话**：SeaTable 是一款「表格 + 数据库」结合的工具（类似在线电子表格，但更强，可以像数据库一样管理数据行）。用这个节点，你可以在 n8n 里自动创建、更新、删除、查询表格里的行（row），比如「把表单收集的数据自动写进 SeaTable 的表格里」。
{% endhint %}

# SeaTable 节点

使用 SeaTable 节点来自动化你在 SeaTable 中的工作，并把它与其它应用集成。n8n 内置支持 SeaTable 的大量功能，包括创建、更新、删除和获取行（row）。

在本页你可以看到 SeaTable 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [SeaTable 凭证](../credentials/seatable.md)。
{% endhint %}

## 操作（Operations）

* Row（行）
    * Create（创建）
    * Delete（删除）
    * Get（获取单个）
    * Get All（获取全部）
    * Update（更新）
