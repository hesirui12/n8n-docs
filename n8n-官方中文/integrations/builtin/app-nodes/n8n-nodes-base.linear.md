{% hint style="info" %}
**大白话**：Linear 是近年来非常流行的「产品研发 / 项目管理」工具（界面简洁、速度快，很多科技公司用它替代 Jira）。这个节点能让你在 n8n 里：给问题（Issue）添加评论（Comment）、添加链接（Add Link），以及创建、删除、获取、更新问题。适合做「GitHub 工单 → 自动同步到 Linear」这类流程。
{% endhint %}

# Linear 节点

使用 Linear 节点来自动化你在 Linear 中的工作，并把它与其它应用集成。n8n 内置支持 Linear 的大量功能，包括创建、更新、删除、获取问题（Issue）。

在本页你可以看到 Linear 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Linear 凭证](../credentials/linear.md)。
{% endhint %}

## 操作

* Comment（评论）
	* Add Comment（添加评论）
* Issue（问题）
	* Add Link（添加链接）
    * Create（创建）
    * Delete（删除）
    * Get（获取单个）
    * Get Many（获取多个）
    * Update（更新）
