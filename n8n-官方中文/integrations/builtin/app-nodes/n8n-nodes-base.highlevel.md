{% hint style="info" %}
**大白话**：HighLevel（也叫 GoHighLevel）是国外很火的「营销 + CRM 客户管理」一体化平台，专门给做本地生意和代理的人用。这个节点能让你在 n8n 里直接增删改查联系人（Contact）、商机（Opportunity）、任务（Task），还能在日历上预约（Book an appointment）和查看空闲时间段（Get free slots）。适合做「表单进来自动建档、销售机会自动跟进」这类流程。
{% endhint %}

# HighLevel 节点

使用 HighLevel 节点来自动化你在 HighLevel 中的工作，并把它与其它应用集成。n8n 内置支持 HighLevel 的大量功能，包括创建、更新、删除、获取联系人（Contact）、商机（Opportunity）和任务（Task），以及在日历中预约和获取空闲时间段。

在本页你可以看到 HighLevel 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [HighLevel 凭证](../credentials/highlevel.md)。
{% endhint %}

## 操作

* Contact（联系人）
	* Create or update（创建或更新）
	* Delete（删除）
	* Get（获取单个）
	* Get many（获取多个）
	* Update（更新）
* Opportunity（商机）
	* Create（创建）
	* Delete（删除）
	* Get（获取单个）
	* Get many（获取多个）
	* Update（更新）
* Task（任务）
	* Create（创建）
	* Delete（删除）
	* Get（获取单个）
	* Get many（获取多个）
	* Update（更新）
* Calendar（日历）
	* Book an appointment（预约）
	* Get free slots（获取空闲时间段）
