{% hint style="info" %}
**大白话**：Mailgun 是面向开发者的邮件发送服务，主打「程序化发信」（API 发信、投递率高、可追踪送达情况），不像 Mailchimp 那样带一堆营销界面。这个节点的功能非常单纯：就是发邮件。适合在系统通知、验证码、订单确认这类场景里自动发信。
{% endhint %}

# Mailgun 节点

使用 Mailgun 节点来自动化你在 Mailgun 中的工作，并把它与其它应用集成。n8n 内置支持使用 Mailgun 发送电子邮件。

在本页你可以看到 Mailgun 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Mailgun 凭证](../credentials/mailgun.md)。
{% endhint %}
