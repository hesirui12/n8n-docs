{% hint style="info" %}
**大白话**：Taiga 是一个开源的敏捷项目管理工具（管用户故事、任务、问题 Bug 用的，类似 Jira 的平替）。这个节点让你在 n8n 里直接对 Taiga 的 Issue（问题）做增删改查。常见场景：别人在 Taiga 里提了 Bug，自动同步到你的钉钉/邮件通知；或者外部系统把问题批量创建进 Taiga。
{% endhint %}

# Taiga 节点

使用 Taiga 节点来自动化你在 Taiga 中的工作，并把它与其它应用集成。n8n 内置支持 Taiga 的大量功能，包括创建、更新、删除和获取 Issue（问题）。

在本页你可以看到 Taiga 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Taiga 凭证](../credentials/taiga.md)。
{% endhint %}

## 操作

- **Issue（问题）**
    - Create an issue（创建问题）
    - Delete an issue（删除问题）
    - Get an issue（获取单个问题）
    - Get all issues（获取全部问题）
    - Update an issue（更新问题）
