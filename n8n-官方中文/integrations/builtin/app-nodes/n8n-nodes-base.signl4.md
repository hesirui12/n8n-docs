{% hint style="info" %}
**大白话**：SIGNL4 是一个「移动告警通知服务」——系统出问题要紧急通知值班的人时，它会通过 App 推送、短信、电话等方式把告警发给值班团队，并且有人「接单」后还可以自动上报。这个节点可以帮你：发送告警（Send an alert）、关闭/解决告警（Resolve an alert）。适合做 IT 监控告警联动、值班调度自动化。
{% endhint %}

# SIGNL4 节点

使用 SIGNL4 节点来自动化你在 SIGNL4 中的工作，并把它与其它应用集成。n8n 支持使用 SIGNL4 发送和解决告警。

在本页你可以看到 SIGNL4 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [SIGNL4 凭证](../credentials/signl4.md)。
{% endhint %}

## 操作

* Alert（告警）
    * Send an alert（发送告警）
    * Resolve an alert（解决/关闭告警）
