# AWS Transcribe 节点

> 💡 **大白话**：AWS Transcribe 是亚马逊的「语音转文字」服务，能把录音、音频自动变成文字稿。用这个节点，你可以在 n8n 里自动创建、查看、删除转写任务，不用自己写代码。

使用 AWS Transcribe 节点自动化 AWS Transcribe 中的工作，并将 AWS Transcribe 与其他应用集成。n8n 内置支持大量 AWS Transcribe 功能，包括创建、删除和获取转写任务。

本页列出了 AWS Transcribe 节点支持的操作，以及更多资源链接。

## 支持的操作（Operations）

**Transcription Job（转写任务）**

- Create a transcription job（创建转写任务）
- Delete a transcription job（删除转写任务）
- Get a transcription job（获取单个转写任务）
- Get all transcriptions job（获取所有转写任务）
