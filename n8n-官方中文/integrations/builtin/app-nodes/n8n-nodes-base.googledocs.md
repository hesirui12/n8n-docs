# Google Docs 节点

> **大白话**：Google Docs 就是谷歌在线文档。这个节点让你在 n8n 工作流里自动创建文档、读取文档内容、往文档里写内容，比如自动生成合同、会议纪要存成在线文档。

使用 Google Docs 节点可以在 Google Docs 中实现工作自动化，并把 Google Docs 与其他应用集成。n8n 内置支持多种 Google Docs 功能，包括创建、更新和获取文档。

本页面列出了 Google Docs 节点支持的操作，以及更多资源的链接。
