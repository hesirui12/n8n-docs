{% hint style="info" %}
**大白话**：Mailjet 是一个邮件 + 短信的群发平台，特色是统计报表做得好、免费额度对新手友好。这个节点支持两件事：发邮件（普通邮件或模板邮件）和发短信。适合做「触发式通知」：有人下单/注册 → 自动发邮件和短信提醒。
{% endhint %}

# Mailjet 节点

使用 Mailjet 节点来自动化你在 Mailjet 中的工作，并把它与其它应用集成。n8n 内置支持 Mailjet 的大量功能，包括发送邮件和短信（SMS）。

在本页你可以看到 Mailjet 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Mailjet 凭证](../credentials/mailjet.md)。
{% endhint %}

## 操作

* Email（邮件）
    * Send an email（发送邮件）
    * Send an email template（发送模板邮件）
* SMS（短信）
    * Send an SMS（发送短信）
