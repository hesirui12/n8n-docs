{% hint style="info" %}
**大白话**：AWS Rekognition 是 AWS 的「图像识别 AI」服务，能识别图片里的人脸、物体、文字、不安全内容等。这个节点目前只有一个操作：分析图片。典型场景：用户上传图片后自动检查内容是否违规，或者自动识别图片里有什么物体并打标签。
{% endhint %}

# AWS Rekognition 节点

使用 AWS Rekognition 节点来自动化你在 AWS Rekognition 中的工作，并把它与其它应用集成。n8n 内置支持 AWS Rekognition 的分析图像功能。

在本页你可以看到 AWS Rekognition 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [AWS Rekognition 凭证](../credentials/aws.md)。
{% endhint %}
