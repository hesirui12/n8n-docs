{% hint style="info" %}
**大白话**：Strava 是运动圈最火的「跑步 / 骑行记录 App」——一次跑步、骑行记录叫一个 Activity（活动）。这个节点可以帮你：创建活动、获取活动信息、获取活动的评论（Comments）、点赞（Kudos）、分段（Laps）、心率/功率区间（Zones），以及更新活动。适合做「运动数据自动同步到表格/仪表盘」「跑完自动发朋友圈通知」这类自动化。
{% endhint %}

# Strava 节点

使用 Strava 节点来自动化你在 Strava 中的工作，并把它与其它应用集成。n8n 内置支持 Strava 的大量功能，包括创建新活动，以及获取活动信息。

在本页你可以看到 Strava 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Strava 凭证](../credentials/strava.md)。
{% endhint %}

## 操作

* Activity（活动）
    * Create a new activity（创建新活动）
    * Get an activity（获取一个活动）
    * Get all activities（获取全部活动）
    * Get all activity comments（获取活动的全部评论）
    * Get all activity kudos（获取活动的全部点赞）
    * Get all activity laps（获取活动的全部分段）
    * Get all activity zones（获取活动的全部区间数据，如心率、功率区间）
    * Update an activity（更新活动）
