# Brandfetch 节点

> 💡 **大白话**：Brandfetch 是一个「品牌信息库」，输入一个公司名/网址，就能查到它的标志（logo）、配色、字体、行业等公开品牌资料。用这个节点，你可以在 n8n 里自动获取某家公司的品牌信息，不用自己写代码。

使用 Brandfetch 节点自动化 Brandfetch 中的工作，并将 Brandfetch 与其他应用集成。n8n 内置支持大量 Brandfetch 功能，包括返回某家公司的信息。

本页列出了 Brandfetch 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Brandfetch 凭据](../credentials/brandfetch.md)。
{% endhint %}

## 支持的操作（Operations）

* Return a company's colors（返回公司的配色）
* Return a company's data（返回公司的数据）
* Return a company's fonts（返回公司的字体）
* Return a company's industry（返回公司所属行业）
* Return a company's logo & icon（返回公司的标志和图标）
