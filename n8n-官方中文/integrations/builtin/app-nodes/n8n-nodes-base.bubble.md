# Bubble 节点

> 💡 **大白话**：Bubble 是一款「无代码建站平台」，用它做出来的网站数据存在「对象」里（类似数据库里的记录）。用这个节点，你可以在 n8n 里自动增删改查 Bubble 里的对象，不用自己写代码。

使用 Bubble 节点自动化 Bubble 中的工作，并将 Bubble 与其他应用集成。n8n 内置支持大量 Bubble 功能，包括创建、删除、获取和更新对象。

本页列出了 Bubble 节点支持的操作，以及更多资源链接。

## 支持的操作（Operations）

* Object（对象）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
