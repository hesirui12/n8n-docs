{% hint style="info" %}
**大白话**：Salesmate 是一款 CRM 销售管理软件，用来管客户、公司、商机（deal）和跟进活动（activity）。用这个节点，你可以在 n8n 里自动创建、更新、删除、查询这些数据，比如「新注册用户自动在 Salesmate 里建一条商机」。
{% endhint %}

# Salesmate 节点

使用 Salesmate 节点来自动化你在 Salesmate 中的工作，并把它与其它应用集成。n8n 内置支持 Salesmate 的大量功能，包括创建、更新、删除和获取活动（activity）、公司（company）和商机（deal）。

在本页你可以看到 Salesmate 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Salesmate 凭证](../credentials/salesmate.md)。
{% endhint %}

## 操作（Operations）

* Activity（活动）
    * Create an activity（创建活动）
    * Delete an activity（删除活动）
    * Get an activity（获取活动）
    * Get all companies（获取全部公司）（注：原文如此，疑为「获取全部活动」）
    * Update an activity（更新活动）
* Company（公司）
    * Create a company（创建公司）
    * Delete a company（删除公司）
    * Get a company（获取公司）
    * Get all companies（获取全部公司）
    * Update a company（更新公司）
* Deal（商机）
    * Create a deal（创建商机）
    * Delete a deal（删除商机）
    * Get a deal（获取商机）
    * Get all deals（获取全部商机）
    * Update a deal（更新商机）
