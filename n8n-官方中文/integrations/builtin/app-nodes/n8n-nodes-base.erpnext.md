# ERPNext 节点

> **大白话**：ERPNext 是一个开源 ERP 系统（管财务、采购、销售、库存等）。这个节点让你在 n8n 里增删改查 ERPNext 的各种单据（Document），比如订单、发票、客户记录等。

用 ERPNext 节点在 ERPNext 里自动化干活，并把 ERPNext 和其他应用串起来。n8n 内置支持 ERPNext 的大量功能，包括创建、更新、检索和删除文档。

本页面列出了 ERPNext 节点支持的所有操作，以及更多资源的链接。

## 支持的操作

**Document（文档/单据）**
- Create a document（创建文档）
- Delete a document（删除文档）
- Retrieve a document（获取单个文档）
- Retrieve all documents（获取全部文档）
- Update a document（更新文档）
