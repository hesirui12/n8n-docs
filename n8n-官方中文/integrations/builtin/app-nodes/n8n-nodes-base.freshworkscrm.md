# Freshworks CRM 节点

> **大白话**：Freshworks CRM 是销售管理软件（管客户、商机、销售活动）。这个节点让你在 n8n 里自动管理客户资料：账户、联系人、商机（Deal）、预约、备注、任务、销售活动等，都能增删改查。

用 Freshworks CRM 节点在 Freshworks CRM 里自动化干活，并把 Freshworks CRM 和其他应用串起来。n8n 内置支持 Freshworks CRM 的大量功能，包括创建、更新、删除和检索账户、预约、联系人、商机、备注、销售活动等等。

本页面列出了 Freshworks CRM 节点支持的所有操作，以及更多资源的链接。

## 支持的操作

* Account（账户）
    * Create an account（创建账户）
    * Delete an account（删除账户）
    * Retrieve an account（获取单个账户）
    * Retrieve all accounts（获取全部账户）
    * Update an account（更新账户）
* Appointment（预约）
    * Create an appointment（创建预约）
    * Delete an appointment（删除预约）
    * Retrieve an appointment（获取单个预约）
    * Retrieve all appointments（获取全部预约）
    * Update an appointment（更新预约）
* Contact（联系人）
    * Create a contact（创建联系人）
    * Delete a contact（删除联系人）
    * Retrieve a contact（获取单个联系人）
    * Retrieve all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Deal（商机/交易）
    * Create a deal（创建商机）
    * Delete a deal（删除商机）
    * Retrieve a deal（获取单个商机）
    * Retrieve all deals（获取全部商机）
    * Update a deal（更新商机）
* Note（备注）
    * Create a note（创建备注）
    * Delete a note（删除备注）
    * Update a note（更新备注）
* Sales Activity（销售活动）
    * Retrieve a sales activity（获取单个销售活动）
    * Retrieve all sales activities（获取全部销售活动）
* Task（任务）
    * Create a task（创建任务）
    * Delete a task（删除任务）
    * Retrieve a task（获取单个任务）
    * Retrieve all tasks（获取全部任务）
    * Update a task（更新任务）
