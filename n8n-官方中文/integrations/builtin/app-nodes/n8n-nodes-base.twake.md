{% hint style="info" %}
**大白话**：Twake 是一款开源团队协作软件（类似 Slack：频道聊天、文件共享等）。这个节点的功能很简单——往 Twake 里发消息。常用场景：工作流处理完一件事，自动在 Twake 频道发条消息通知团队。
{% endhint %}

# Twake 节点

使用 Twake 节点来自动化你在 Twake 中的工作，并把它与其它应用集成。n8n 支持用 Twake 发送消息。

在本页你可以看到 Twake 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Twake 凭证](../credentials/twake.md)。
{% endhint %}

## 操作

* Message（消息）
    * Send a message（发送消息）
