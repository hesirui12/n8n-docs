**大白话**：Shopify 是全球最流行的「独立站电商平台」——你在上面开店卖货。这个节点可以帮你：管理订单（Order，增删改查）和管理商品（Product，增删改查）。适合做订单自动同步到 ERP/财务系统、库存更新、新品上架等自动化。
{% endhint %}

# Shopify 节点

使用 Shopify 节点来自动化你在 Shopify 中的工作，并把它与其它应用集成。n8n 内置支持 Shopify 的大量功能，包括创建、更新、删除、获取订单和商品。

在本页你可以看到 Shopify 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Shopify 凭证](../credentials/shopify.md)。
{% endhint %}

## 操作

* Order（订单）
    * Create an order（创建订单）
    * Delete an order（删除订单）
    * Get an order（获取订单）
    * Get all orders（获取全部订单）
    * Update an order（更新订单）
* Product（商品）
    * Create a product（创建商品）
    * Delete a product（删除商品）
    * Get a product（获取商品）
    * Get all products（获取全部商品）
    * Update a product（更新商品）
