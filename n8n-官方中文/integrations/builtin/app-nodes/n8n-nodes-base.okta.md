{% hint style="info" %}
**大白话**：Okta 是企业级的「身份认证与访问管理」平台（帮公司统一管理员工账号、登录权限、单点登录 SSO）。这个节点让你在 n8n 里直接管理 Okta 的用户账号：新建用户、删除用户、查看用户详情、批量获取用户、更新用户资料——适合做「新员工入职自动开账号、离职自动关账号」这类自动化。
{% endhint %}

# Okta 节点

使用 Okta 节点来自动化你在 Okta 中的工作，并把它与其它应用集成。n8n 内置支持 Okta 的大量功能，包括创建、更新和删除用户。

在本页你可以看到 Okta 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于此节点的认证信息，你可以在[这里](../credentials/okta.md)找到。

{% endhint %}

## 操作

- User（用户）
    - Create a new user（创建新用户）
    - Delete an existing user（删除现有用户）
    - Get details of a user（获取用户详情）
    - Get many users（获取多个用户）
    - Update an existing user（更新现有用户）
