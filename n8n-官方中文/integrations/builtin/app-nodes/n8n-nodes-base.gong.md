# Gong 节点

> **大白话**：Gong 是一款销售通话记录与分析工具，会自动录制和分析销售团队的通话。这个节点让你在 n8n 工作流里读取 Gong 的通话记录和用户信息，把它们和其他应用连起来用。

使用 Gong 节点可以在 Gong 中实现工作自动化，并把 Gong 与其他应用集成。n8n 内置支持多种 Gong 功能，包括获取单个或多个通话（Call）和用户（User）。

本页面列出了 Gong 节点支持的操作，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

此节点的认证信息请参考 [这里](../credentials/gong.md)。
{% endhint %}

## 操作

* Call（通话）
	* Get（获取单个）
	* Get Many（获取多个）
* User（用户）
	* Get（获取单个）
	* Get Many（获取多个）
