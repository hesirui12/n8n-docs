{% hint style="info" %}
**大白话**：Pushover 是一款跨平台推送通知服务，可以把消息实时推到手机（Android/iOS）和桌面设备上。用这个节点，你可以在 n8n 里给手机发推送通知，比如「工作流跑完了」「定时任务出错了」，是最常用的告警通知节点之一。
{% endhint %}

# Pushover 节点

使用 Pushover 节点来自动化你在 Pushover 中的工作，并把它与其它应用集成。n8n 支持用 Pushover 发送推送通知。

在本页你可以看到 Pushover 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Pushover 凭证](../credentials/pushover.md)。
{% endhint %}
