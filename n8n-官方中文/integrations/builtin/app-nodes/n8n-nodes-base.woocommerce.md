{% hint style="info" %}
**大白话**：WooCommerce 是 WordPress 上最流行的「电商插件」——把 WordPress 网站变成网店。这个节点可以帮你：管理客户（Customer）、订单（Order）、商品（Product）的增删改查。适合做电商自动化，比如新订单自动通知、自动更新库存、批量管理商品。
{% endhint %}

# WooCommerce 节点

使用 WooCommerce 节点来自动化你在 WooCommerce 中的工作，并把它与其它应用集成。n8n 内置支持 WooCommerce 的大量功能，包括创建和删除客户、订单和商品。

在本页你可以看到 WooCommerce 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [WooCommerce 凭证](../credentials/woocommerce.md)。
{% endhint %}

（官方此处嵌入了通用资源组件，此处从略。）

## 操作

* Customer（客户）
    * Create a customer（创建客户）
    * Delete a customer（删除客户）
    * Retrieve a customer（获取客户）
    * Retrieve all customers（获取全部客户）
    * Update a customer（更新客户）
* Order（订单）
    * Create a order（创建订单）
    * Delete a order（删除订单）
    * Get a order（获取订单）
    * Get all orders（获取全部订单）
    * Update an order（更新订单）
* Product（商品）
    * Create a product（创建商品）
    * Delete a product（删除商品）
    * Get a product（获取商品）
    * Get all products（获取全部商品）
    * Update a product（更新商品）
