{% hint style="info" %}
**大白话**：Pushbullet 是一款跨设备的消息推送工具，可以把通知、链接、文件推送到你的手机、电脑和浏览器。用这个节点，你可以在 n8n 里自动发送推送（比如工作流出错时发条通知到手机）、以及管理（查询、删除、更新）已有的推送消息。
{% endhint %}

# Pushbullet 节点

使用 Pushbullet 节点来自动化你在 Pushbullet 中的工作，并把它与其它应用集成。n8n 内置支持 Pushbullet 的大量功能，包括创建、更新、删除和获取推送（push）。

在本页你可以看到 Pushbullet 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Pushbullet 凭证](../credentials/pushbullet.md)。
{% endhint %}

## 操作（Operations）

* Push（推送）
    * Create a push（创建推送）
    * Delete a push（删除推送）
    * Get all pushes（获取全部推送）
    * Update a push（更新推送）
