# AWS SQS 节点

> 💡 **大白话**：AWS SQS 是亚马逊的「消息队列」，就像排队叫号的系统：先放进去的消息先被取走，用来让不同的程序之间安全地传消息。用这个节点，你可以在 n8n 里自动往队列里发消息，不用自己写代码。

使用 AWS SQS 节点自动化 AWS SQS 中的工作，并将 AWS SQS 与其他应用集成。n8n 内置支持大量 AWS SQS 功能，包括发送消息。

本页列出了 AWS SQS 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [AWS SQS 凭据](../credentials/aws.md)。
{% endhint %}
