# Line 节点

使用 Line 节点来自动化你在 Line 中的工作，并把它与其它应用集成。n8n 内置支持 Line 的大量功能，包括发送通知。

在本页你可以看到 Line 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Line 凭证](../credentials/line.md)。
{% endhint %}
