# Google Cloud Realtime Database 节点

> **大白话**：Realtime Database 是谷歌的实时云端数据库，特点是数据一变，所有连着它的客户端立刻同步。这个节点让你在 n8n 工作流里读写这个数据库，比如存数据、删数据、往列表里追加数据。

使用 Google Cloud Realtime Database 节点可以在 Google Cloud Realtime Database 中实现工作自动化，并把 Google Cloud Realtime Database 与其他应用集成。n8n 内置支持多种 Google Cloud Realtime Database 功能，包括写入、删除、获取和追加数据库数据。

本页面列出了 Google Cloud Realtime Database 节点支持的操作，以及更多资源的链接。

## 操作

* Write data to a database（向数据库写入数据）
* Delete data from a database（从数据库删除数据）
* Get a record from a database（从数据库获取一条记录）
* Append to a list of data（向数据列表追加内容）
* Update item on a database（更新数据库中的一项）
