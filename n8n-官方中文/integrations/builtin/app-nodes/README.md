{% hint style="info" %}
**大白话**：这一节是整个「应用节点」文档的目录首页。所谓「应用节点」（App nodes），就是 n8n 里用来连接外部软件（比如 Gmail、Airtable、AWS 等）的现成积木块。你只需要拖一个节点进画布、填好账号和参数，就能让 n8n 帮你操作那个软件，不用自己写代码。下面的每个子页面都会介绍某个具体节点：它能干什么（大白话）、怎么连账号（凭证）、支持哪些操作（增删改查等）。页面按英文字母顺序排列，例如 A 开头有 Action Network、ActiveCampaign、Adalo，再到 AWS 全家桶等。
{% endhint %}

# 操作库

本部分提供关于 n8n 的 Actions（操作）的信息。

本节包含以下内容：

- 节点支持的操作列表（Operations）
- 官方集成模板与示例链接
- 凭证（Credentials）配置指引
- 常见问题（Common Issues）排查
