{% hint style="info" %}
**大白话**：Mandrill 是 Mailchimp 公司出的「交易类邮件」发送服务（比如注册确认、密码找回这种一封封单独发的邮件，跟群发营销邮件是两回事）。这个节点就两个操作：按模板发消息，或按 HTML 代码发消息。适合在 n8n 里做系统通知类的自动发信。
{% endhint %}

# Mandrill 节点

使用 Mandrill 节点来自动化你在 Mandrill 中的工作，并把它与其它应用集成。n8n 支持使用 Mandrill 发送基于模板或 HTML 的消息。

在本页你可以看到 Mandrill 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Mandrill 凭证](../credentials/mandrill.md)。
{% endhint %}

## 操作

* Message（消息）
    * Send message based on template.（基于模板发送消息）
    * Send message based on HTML.（基于 HTML 发送消息）

## 模板与示例

[浏览 Mandrill 节点的官方集成模板](https://n8n.io/integrations/mandrill)，或[搜索全部模板](https://n8n.io/workflows/)。
