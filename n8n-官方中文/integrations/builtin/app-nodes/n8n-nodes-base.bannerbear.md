# Bannerbear 节点

> 💡 **大白话**：Bannerbear 是一个「自动做图」工具：你做好一个图片模板，它就能往模板里自动填文字/数据，批量生成图片（比如商品图、社交媒体横幅）。用这个节点，你可以在 n8n 里自动创建图片、获取模板，不用自己写代码。

使用 Bannerbear 节点自动化 Bannerbear 中的工作，并将 Bannerbear 与其他应用集成。n8n 内置支持大量 Bannerbear 功能，包括创建和获取图片与模板。

本页列出了 Bannerbear 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Bannerbear 凭据](../credentials/bannerbear.md)。
{% endhint %}

## 支持的操作（Operations）

* Image（图片）
    * Create an image（创建图片）
    * Get an image（获取图片）
* Template（模板）
    * Get a template（获取模板）
    * Get all templates（获取所有模板）
