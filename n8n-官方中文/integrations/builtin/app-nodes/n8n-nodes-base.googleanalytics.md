# Google Analytics 节点

> **大白话**：Google Analytics 是谷歌的网站流量分析工具。这个节点让你在 n8n 工作流里自动拉取网站报告数据和用户行为记录，比如定时把访问量数据同步到数据库或发送报表。

使用 Google Analytics 节点可以在 Google Analytics 中实现工作自动化，并把 Google Analytics 与其他应用集成。n8n 内置支持多种 Google Analytics 功能，包括返回报告和用户活动数据。

本页面列出了 Google Analytics 节点支持的操作，以及更多资源的链接。

**凭证（Credentials）**

关于如何设置认证，请参考 [Google Analytics 凭证](../credentials/google/README.md)。
