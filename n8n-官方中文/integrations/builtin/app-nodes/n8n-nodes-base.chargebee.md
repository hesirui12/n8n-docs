# Chargebee 节点

> 💡 **大白话**：Chargebee 是一款「订阅计费平台」，专门处理订阅、账单、发票等收费流程。用这个节点，你可以在 n8n 里自动创建客户、获取发票、取消或删除订阅，不用自己写代码。

使用 Chargebee 节点自动化 Chargebee 中的工作，并将 Chargebee 与其他应用集成。n8n 内置支持大量 Chargebee 功能，包括创建客户、返回发票、取消订阅。

本页列出了 Chargebee 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Chargebee 凭据](../credentials/chargebee.md)。
{% endhint %}

## 支持的操作（Operations）

* Customer（客户）
    * Create a customer（创建客户）
* Invoice（发票）
    * Return the invoices（返回发票列表）
    * Get URL for the invoice PDF（获取发票 PDF 的链接）
* Subscription（订阅）
    * Cancel a subscription（取消订阅）
    * Delete a subscription（删除订阅）
