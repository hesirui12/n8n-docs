# Drift 节点

> **大白话**：Drift 是一款客户沟通/营销工具（类似在线聊天客服+邮件营销）。这个节点让你在 n8n 里直接操作 Drift 的联系人——新建、删除、修改、查询都能做，不用手动登录 Drift 后台。

用 Drift 节点在 Drift 里自动化干活，并把 Drift 和其他应用串起来。n8n 内置支持 Drift 的大量功能，包括创建、更新、删除和获取联系人。

本页面列出了 Drift 节点支持的所有操作，以及更多资源的链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何配置认证，请参考 [Drift 凭据](../credentials/drift.md)。
{% endhint %}

## 支持的操作

* Contact（联系人）
    * Create a contact（创建联系人）
    * Get custom attributes（获取自定义属性）
    * Delete a contact（删除联系人）
    * Get a contact（获取联系人）
    * Update a contact（更新联系人）
