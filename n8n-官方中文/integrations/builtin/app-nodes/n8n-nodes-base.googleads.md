# Google Ads 节点

> **大白话**：Google Ads 是谷歌的付费广告平台。这个节点让你在 n8n 工作流里自动读取广告系列（Campaign）的信息，比如把广告数据拉下来存进表格或做监控。

使用 Google Ads 节点可以在 Google Ads 中实现工作自动化，并把 Google Ads 与其他应用集成。n8n 内置支持多种 Google Ads 功能，包括获取广告系列。

本页面列出了 Google Ads 节点支持的操作，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Google Ads 凭证](../credentials/google/README.md)。
{% endhint %}

## 操作

* Campaign（广告系列）
    * Get all campaigns（获取全部广告系列）
    * Get a campaign（获取单个广告系列）
