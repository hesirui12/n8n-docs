# Bitly 节点

> 💡 **大白话**：Bitly 是「短链接」服务，能把长长的网址压缩成短链接，还能统计点击量。用这个节点，你可以在 n8n 里自动创建、获取、更新短链接，不用自己写代码。

使用 Bitly 节点自动化 Bitly 中的工作，并将 Bitly 与其他应用集成。n8n 内置支持大量 Bitly 功能，包括创建、获取和更新链接。

本页列出了 Bitly 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Bitly 凭据](../credentials/bitly.md)。
{% endhint %}

## 支持的操作（Operations）

* Link（链接）
    * Create a link（创建链接）
    * Get a link（获取链接）
    * Update a link（更新链接）
