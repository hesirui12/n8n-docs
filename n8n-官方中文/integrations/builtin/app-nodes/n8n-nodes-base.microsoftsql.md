# Microsoft SQL 节点

> 💡 **大白话**：Microsoft SQL Server 是微软的「数据库」，用来存表格数据。用这个节点，你可以让 n8n 直接对数据库执行 SQL 语句（增、删、改、查），把数据存进去或取出来，不用自己写连接代码。

使用 Microsoft SQL 节点来自动化你在 Microsoft SQL 中的工作，并把它与其它应用集成。n8n 内置支持 Microsoft SQL 的大量功能，包括执行 SQL 查询、向数据库插入行。

在本页你可以看到 Microsoft SQL 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}

## 操作（Operations）

* 执行 SQL 查询（Execute an SQL query）
* 在数据库中插入行（Insert rows in database）
* 在数据库中更新行（Update rows in database）
* 在数据库中删除行（Delete rows in database）
