# Freshdesk 节点

> **大白话**：Freshdesk 是一个客服工单系统（客户发来问题，客服在系统里处理）。这个节点让你在 n8n 里自动管理「联系人」和「工单」：创建、修改、删除、查询都能做，比如自动把新客户创建成工单。

用 Freshdesk 节点在 Freshdesk 里自动化干活，并把 Freshdesk 和其他应用串起来。n8n 内置支持 Freshdesk 的大量功能，包括创建、更新、删除和获取联系人与工单。

本页面列出了 Freshdesk 节点支持的所有操作，以及更多资源的链接。

**凭据（Credentials）**

关于如何配置认证，请参考 [Freshdesk 凭据](../credentials/freshdesk.md)。
{% endhint %}

## 支持的操作

* Contact（联系人）
    * Create a new contact（创建新联系人）
    * Delete a contact（删除联系人）
    * Get a contact（获取单个联系人）
    * Get all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Ticket（工单）
    * Create a new ticket（创建新工单）
    * Delete a ticket（删除工单）
    * Get a ticket（获取单个工单）
    * Get all tickets（获取全部工单）
    * Update a ticket（更新工单）
