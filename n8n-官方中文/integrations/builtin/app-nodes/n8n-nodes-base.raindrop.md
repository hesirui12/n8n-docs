{% hint style="info" %}
**大白话**：Raindrop 是一款书签（收藏夹）管理工具，用来保存和整理网页书签，支持分类（collection）和标签（tag）。用这个节点，你可以在 n8n 里自动创建、更新、删除、查询书签和收藏分类，比如「把老板发来的网址自动存进书签」。
{% endhint %}

# Raindrop 节点

使用 Raindrop 节点来自动化你在 Raindrop 中的工作，并把它与其它应用集成。n8n 内置支持 Raindrop 的大量功能，包括获取用户、删除标签，以及创建、更新、删除和获取收藏分类（collection）和书签（bookmark）。

在本页你可以看到 Raindrop 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Raindrop 凭证](../credentials/raindrop.md)。
{% endhint %}

## 操作（Operations）

* Bookmark（书签）
    * Create（创建）
    * Delete（删除）
    * Get（获取单个）
    * Get All（获取全部）
    * Update（更新）
* Collection（收藏分类）
    * Create（创建）
    * Delete（删除）
    * Get（获取单个）
    * Get All（获取全部）
    * Update（更新）
* Tag（标签）
    * Delete（删除）
    * Get All（获取全部）
* User（用户）
    * Get（获取用户信息）
