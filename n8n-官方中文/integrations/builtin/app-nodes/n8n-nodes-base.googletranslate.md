# Google Translate 节点

> 💡 **大白话**：就是谷歌翻译。用这个节点，n8n 可以在工作流里自动翻译文字——比如把客户消息自动翻成中文再回复，或者把表单内容批量翻译成多国语言。功能就一个：Translate data（翻译数据）。

使用 Google Translate 节点自动化 Google Translate 中的工作，并将 Google Translate 与其他应用集成。n8n 内置支持大量 Google Translate 功能，包括翻译语言。

本页列出了 Google Translate 节点支持的操作，以及更多资源链接。
