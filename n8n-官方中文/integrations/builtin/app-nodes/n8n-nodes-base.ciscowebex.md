# Webex by Cisco 节点

> 💡 **大白话**：Webex（思科）是一款「视频会议+团队聊天」软件。用这个节点，你可以在 n8n 里自动创建、获取、更新、删除会议和消息，不用自己写代码。

使用 Webex by Cisco 节点自动化 Webex 中的工作，并将 Webex 与其他应用集成。n8n 内置支持大量 Webex 功能，包括创建、获取、更新和删除会议与消息。

本页列出了 Webex 节点支持的操作，以及更多资源链接。

关于如何设置认证，请参考 [Webex 凭据](../credentials/ciscowebex.md)。

{% endhint %}

## 支持的操作（Operations）

* Meeting（会议）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Message（消息）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
