# E-goi 节点

> **大白话**：E-goi 是一个做邮件/短信营销的平台（订阅用户、发营销信息用的）。这个节点让你在 n8n 里管理它的订阅会员：新增、查看、批量查询、修改会员信息。

用 E-goi 节点在 E-goi 里自动化干活，并把 E-goi 和其他应用串起来。n8n 内置支持 E-goi 的大量功能，包括创建、更新、删除和获取联系人。

本页面列出了 E-goi 节点支持的所有操作，以及更多资源的链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何配置认证，请参考 [E-goi 凭据](../credentials/egoi.md)。
{% endhint %}

## 支持的操作

**Contact（联系人/会员）**

- Create a member（创建会员）
- Get a member（获取单个会员）
- Get all members（获取全部会员）
- Update a member（更新会员信息）
