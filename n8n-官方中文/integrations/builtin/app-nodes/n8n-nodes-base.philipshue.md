{% hint style="info" %}
**大白话**：Philips Hue 是飞利浦的智能灯泡系统（手机 App 或自动化控制灯光颜色、亮度）。这个节点让你在 n8n 里直接管理 Hue 的灯（Light）：获取单个/全部灯、更新灯的状态（开关、亮度、颜色）、删除灯——适合做「天黑自动开灯」「人下班自动关灯」之类的智能家居自动化。
{% endhint %}

# Philips Hue 节点

使用 Philips Hue 节点来自动化你在 Philips Hue 中的工作，并把它与其它应用集成。n8n 内置支持 Philips Hue 的大量功能，包括删除、获取和更新灯（light）。

在本页你可以看到 Philips Hue 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Philips Hue 凭证](../credentials/philipshue.md)。
{% endhint %}

## 操作

* Light（灯）
    * Delete a light（删除一盏灯）
    * Retrieve a light（获取一盏灯）
    * Retrieve all lights（获取全部灯）
    * Update a light（更新一盏灯）
