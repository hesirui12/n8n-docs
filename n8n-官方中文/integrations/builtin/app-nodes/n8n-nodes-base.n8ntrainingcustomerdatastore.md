# 客户数据存储（n8n 培训）节点

> 💡 **大白话**：这个节点是 n8n 官方的「教学专用假数据节点」。它只在你跟着 n8n 的新手入门教程学习时才用得上，作用是提供一批假的客户数据供练习，没有别的实际功能，正式工作中用不到它。

请仅将此节点用于 n8n 新用户入门教程。它提供用于测试的假数据（dummy data），没有其他功能。
