{% hint style="info" %}
**大白话**：Pushcut 是一款 iOS 自动化通知工具，可以给 iPhone/iPad 发送带按钮的智能通知，点通知按钮还能触发快捷指令。用这个节点，你可以在 n8n 里自动给 iOS 设备发通知提醒。
{% endhint %}

# Pushcut 节点

使用 Pushcut 节点来自动化你在 Pushcut 中的工作，并把它与其它应用集成。n8n 支持用 Pushcut 发送通知。

在本页你可以看到 Pushcut 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Pushcut 凭证](../credentials/pushcut.md)。
{% endhint %}

## 操作（Operations）

* Notification（通知）
    * Send a notification（发送通知）
