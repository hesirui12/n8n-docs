{% hint style="info" %}
**大白话**：Mailcheck 是一个专门帮你「验邮箱」的服务——检查某个邮箱地址是否存在、能不能收信，防止你给无效邮箱发邮件。这个节点就一个操作：把邮箱地址丢进去，它帮你查。适合在注册、留资等流程里过滤掉假邮箱。
{% endhint %}

# Mailcheck 节点

使用 Mailcheck 节点来自动化你在 Mailcheck 中的工作，并把它与其它应用集成。n8n 内置支持 Mailcheck 的大量功能，包括检查邮箱地址。

在本页你可以看到 Mailcheck 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Mailcheck 凭证](../credentials/mailcheck.md)。
{% endhint %}

（官方此处嵌入了通用资源组件，此处从略。）

## 操作

* Email（邮箱）
    * Check（检查邮箱地址是否有效）
