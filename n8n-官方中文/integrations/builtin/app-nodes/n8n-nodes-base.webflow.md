{% hint style="info" %}
**大白话**：Webflow 是一个「可视化建站工具」——不用写代码就能做网站，还能用 CMS（内容管理系统）存数据。这个节点可以帮你：对 Webflow CMS 里的「项目/条目（Item，比如文章、产品）」做增删改查。适合做内容自动化，比如把表单提交或数据库记录自动写入网站。
{% endhint %}

# Webflow 节点

使用 Webflow 节点来自动化你在 Webflow 中的工作，并把它与其它应用集成。n8n 内置支持 Webflow 的大量功能，包括创建、更新、删除和获取条目。

在本页你可以看到 Webflow 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Webflow 凭证](../credentials/webflow.md)。
{% endhint %}

## 操作

* Item（条目）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
