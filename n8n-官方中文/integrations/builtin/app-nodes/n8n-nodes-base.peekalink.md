{% hint style="info" %}
**大白话**：Peekalink 是一个「链接预览服务」——你给它一个网址，它返回该链接的预览信息（网页标题、描述、缩略图等，类似微信里发链接显示的卡片）。这个节点让你在 n8n 里检查某个链接是否已有预览，或直接获取链接的预览内容。
{% endhint %}

# Peekalink 节点

使用 Peekalink 节点来自动化你在 Peekalink 中的工作，并把它与其它应用集成。n8n 支持用 Peekalink 检查和查看链接。

在本页你可以看到 Peekalink 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Peekalink 凭证](../credentials/peekalink.md)。
{% endhint %}

## 操作

* Check whether preview for a given link is available（检查某个链接是否已有预览可用）
* Return the preview for a link（返回链接的预览）
