{% hint style="info" %}
**大白话**：WhatsApp Business Cloud 是 WhatsApp 官方的「企业版 API」——通过它，你的企业可以用一个 WhatsApp 商务号码自动收发消息（发营销/通知消息、收客户咨询）。这个节点可以帮你：发消息（Message：Send 发送、Send Template 发模板消息、Send and Wait for Response 发送并等待回复），以及上传/下载/删除媒体文件（Media）。适合做客服自动回复、订单通知。
{% endhint %}

# WhatsApp Business Cloud 节点

使用 WhatsApp Business Cloud 节点来自动化你在 WhatsApp Business 中的工作，并把它与其它应用集成。n8n 内置支持 WhatsApp Business 的大量功能，包括发送消息，以及上传、下载和删除媒体文件。

在本页你可以看到 WhatsApp Business Cloud 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [WhatsApp Business Cloud 凭证](../../credentials/whatsapp.md)。
{% endhint %}

## 操作

* Message（消息）
	* Send（发送）
	* Send and Wait for Response（发送并等待回复）
	* Send Template（发送模板消息）
* Media（媒体）
	* Upload（上传）
	* Download（下载）
	* Delete（删除）
