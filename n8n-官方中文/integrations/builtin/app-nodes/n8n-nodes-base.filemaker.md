# FileMaker 节点

> **大白话**：FileMaker 是苹果生态里常用的低代码数据库/表单软件。这个节点让你在 n8n 里操作 FileMaker 里的记录（Record）：查找、读取、新增、编辑、复制、删除，还能执行 FileMaker 脚本。

用 FileMaker 节点在 FileMaker 里自动化干活，并把 FileMaker 和其他应用串起来。n8n 内置支持 FileMaker 的大量功能，包括创建、查找、获取、编辑和复制文件。

本页面列出了 FileMaker 节点支持的所有操作，以及更多资源的链接。

## 支持的操作

- Find Records（查找记录）
- Get Records（获取记录）
- Get Records by Id（按 ID 获取记录）
- Perform Script（执行脚本）
- Create Record（创建记录）
- Edit Record（编辑记录）
- Duplicate Record（复制记录）
- Delete Record（删除记录）
