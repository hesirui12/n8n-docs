# Mindee 节点

> 💡 **大白话**：Mindee 是一个「智能文档识别」服务，专门帮你把发票、小票等纸质单据上的文字和数据自动识别出来。用这个节点，你可以让 n8n 把发票（Invoice）或收据（Receipt）图片传给它，自动识别出金额、日期、商家等结构化数据，省去手动录入。

使用 Mindee 节点来自动化你在 Mindee 中的工作，并把它与其它应用集成。n8n 内置支持 Mindee 的大量功能，包括预测发票内容。

在本页你可以看到 Mindee 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Mindee 凭证](../credentials/mindee.md)。
{% endhint %}

- **Invoice（发票）**
    - Predict（预测/识别）
- **Receipt（收据）**
    - Predict（预测/识别）
