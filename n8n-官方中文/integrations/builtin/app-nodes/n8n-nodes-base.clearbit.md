# Clearbit 节点

> **大白话**：Clearbit 是一个帮你"查底细"的服务——输入一个邮箱或公司域名，就能查出这家公司或这个人是谁、规模多大、做什么业务，还能自动补全公司名称并拿到 Logo 和官网。这个节点就是让 n8n 能直接调用 Clearbit，把这些查询动作自动跑起来，省得你手动去网站一个个查。

使用 Clearbit 节点可以自动化处理 Clearbit 里的工作，并让 Clearbit 与其他应用程序互通。n8n 内置支持 Clearbit 的众多功能，包括自动补全公司名称、查询公司与个人资料等。

本页列出了 Clearbit 节点支持的操作清单，以及更多资源的链接。

{% endhint %}

## 支持的操作

* Company（公司）
    * 自动补全公司名称，并获取公司 Logo 和域名
    * 根据邮箱或域名查询个人和公司的数据
* Person（个人）
    * 根据邮箱或域名查询个人和公司的数据
