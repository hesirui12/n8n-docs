{% hint style="info" %}
**大白话**：PostHog 是一款开源的用户行为分析工具，用来统计用户在你的产品里干了什么（比如打开了哪个页面、点了哪个按钮）。用这个节点，你可以在 n8n 里自动创建事件、追踪页面访问、创建别名和用户身份，把业务数据实时同步到 PostHog 做分析。
{% endhint %}

# PostHog 节点

使用 PostHog 节点来自动化你在 PostHog 中的工作，并把它与其它应用集成。n8n 内置支持 PostHog 的大量功能，包括创建别名（alias）、事件（event）和身份（identity），以及追踪页面（page tracking）。

在本页你可以看到 PostHog 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [PostHog 凭证](../credentials/posthog.md)。
{% endhint %}

## 操作（Operations）

* Alias（别名）
    * Create an alias（创建别名）
* Event（事件）
    * Create an event（创建事件）
* Identity（身份）
    * Create（创建身份）
* Track（追踪）
    * Track a page（追踪一个页面访问）
    * Track a screen（追踪一个屏幕/界面访问）
