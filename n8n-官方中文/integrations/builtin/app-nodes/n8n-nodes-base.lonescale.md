{% hint style="info" %}
**大白话**：LoneScale 是一个「线索数据收集 / 联系人数据管道」服务（把分散在各处的 B2B 联系人数据整合起来）。这个节点功能很简单，就两件事：创建 List（列表）和创建 Item（条目）。另外它还配有一个触发器节点，可以看[这里](../trigger-nodes/n8n-nodes-base.lonescaletrigger.md)的文档。
{% endhint %}

# LoneScale 节点

使用 LoneScale 节点来自动化你在 LoneScale 中的工作，并把它与其它应用集成。n8n 内置支持管理 LoneScale 中的列表（List）和条目（Item）。

在本页你可以看到 LoneScale 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于这个节点的认证信息，请看[这里](../credentials/lonescale.md)。
{% endhint %}

## 操作

* List（列表）
	* Create（创建）
* Item（条目）
	* Create（创建）

## 模板与示例

[浏览 LoneScale 节点的官方集成模板](https://n8n.io/integrations/lonescale)，或[搜索全部模板](https://n8n.io/workflows/)。
