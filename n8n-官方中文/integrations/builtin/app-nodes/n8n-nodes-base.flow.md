# Flow 节点

> **大白话**：Flow（getflow.com）是一个任务管理/项目管理工具。这个节点让你在 n8n 里自动创建任务、更新任务、查询单个或全部任务，把任务管理融入自动化流程。

用 Flow 节点在 Flow 里自动化干活，并把 Flow 和其他应用串起来。n8n 内置支持 Flow 的大量功能，包括创建、更新和获取任务。

本页面列出了 Flow 节点支持的所有操作，以及更多资源的链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何配置认证，请参考 [Flow 凭据](../credentials/flow.md)。
{% endhint %}

## 支持的操作

* Task（任务）
    * Create a new task（创建新任务）
    * Update a task（更新任务）
    * Get a task（获取单个任务）
    * Get all the tasks（获取全部任务）
