{% hint style="info" %}
**大白话**：Rocket.Chat 是一款开源的团队聊天/群组通讯软件（类似自托管的 Slack）。用这个节点，你可以在 n8n 里自动往频道发消息，或给某个用户发私信（direct message），比如「新订单来了自动在团队频道里喊一声」。
{% endhint %}

# Rocket.Chat 节点

使用 Rocket.Chat 节点来自动化你在 Rocket.Chat 中的工作，并把它与其它应用集成。n8n 支持用 Rocket.Chat 向频道发布消息，以及发送私信（direct message）。

在本页你可以看到 Rocket.Chat 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Rocket.Chat 凭证](../credentials/rocketchat.md)。
{% endhint %}

    * Post a message to a channel or a direct message（向频道发布消息，或发送一条私信）
