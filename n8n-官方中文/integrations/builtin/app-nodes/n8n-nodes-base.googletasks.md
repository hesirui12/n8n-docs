# Google Tasks 节点

> 💡 **大白话**：Google Tasks 是谷歌的「待办事项/任务清单」应用。用这个节点，n8n 可以自动往任务清单里加任务、删除任务、读取任务、更新任务——比如收到新邮件就自动生成一条待办。

使用 Google Tasks 节点自动化 Google Tasks 中的工作，并将 Google Tasks 与其他应用集成。n8n 内置支持大量 Google Tasks 功能，包括添加、更新和获取联系人。

本页列出了 Google Tasks 节点支持的操作，以及更多资源链接。

## 支持的操作（Operations）

* Task（任务）
    * Add a task to task list（把任务添加到任务清单）
    * Delete a task（删除任务）
    * Retrieve a task（获取单个任务）
    * Retrieve all tasks from a task list（获取任务清单中的所有任务）
    * Update a task（更新任务）
