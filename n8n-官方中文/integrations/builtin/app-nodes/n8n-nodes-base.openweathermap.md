{% hint style="info" %}
**大白话**：OpenWeatherMap 是知名天气数据服务商。这个节点让你在 n8n 里直接查天气：获取某个地点的「当前天气」，或者「未来 5 天天气预报」。适合做「天气不好自动提醒」「根据天气调整内容」之类的自动化。
{% endhint %}

# OpenWeatherMap 节点

使用 OpenWeatherMap 节点来自动化你在 OpenWeatherMap 中的工作，并把它与其它应用集成。n8n 支持通过 OpenWeatherMap 获取当前和未来的天气数据。

在本页你可以看到 OpenWeatherMap 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [OpenWeatherMap 凭证](../credentials/openweathermap.md)。
{% endhint %}

## 操作

* Returns the current weather data（返回当前天气数据）
* Returns the weather data for the next 5 days（返回未来 5 天的天气数据）
