# Google Cloud Natural Language 节点

> **大白话**：Natural Language 是谷歌的文本分析 AI 服务，能读懂一段文字的情感倾向。这个节点让你在 n8n 工作流里自动分析文本，比如分析用户评价是好评还是差评。

使用 Google Cloud Natural Language 节点可以在 Google Cloud Natural Language 中实现工作自动化，并把 Google Cloud Natural Language 与其他应用集成。n8n 内置支持多种 Google Cloud Natural Language 功能，包括分析文档。

本页面列出了 Google Cloud Natural Language 节点支持的操作，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Google Cloud Natural Language 凭证](../credentials/google/README.md)。
{% endhint %}

## 操作

* Document（文档）
    * Analyze Sentiment（情感分析）
