# Google BigQuery 节点

> **大白话**：BigQuery 是谷歌的云端大数据仓库，可以分析海量数据。这个节点让你在 n8n 工作流里直接对 BigQuery 执行 SQL 查询、插入数据，比如把订单数据灌进数据仓库或定时跑分析。

使用 Google BigQuery 节点可以在 Google BigQuery 中实现工作自动化，并把 Google BigQuery 与其他应用集成。n8n 内置支持多种 Google BigQuery 功能，包括创建和获取记录。

本页面列出了 Google BigQuery 节点支持的操作，以及更多资源的链接。
