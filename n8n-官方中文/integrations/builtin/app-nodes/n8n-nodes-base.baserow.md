# Baserow 节点

> 💡 **大白话**：Baserow 是一款开源的「在线表格数据库」，像 Excel 和数据库的结合体，数据存在「表」里。用这个节点，你可以在 n8n 里自动增删改查表格里的「行」数据（支持一次操作多行），不用自己写代码。

使用 Baserow 节点自动化 Baserow 中的工作，并将 Baserow 与其他应用集成。n8n 内置支持大量 Baserow 功能，包括创建、获取、检索和更新行。

本页列出了 Baserow 节点支持的操作，以及更多资源链接。

## 支持的操作（Operations）

* Row（行）
    * Create multiple rows（创建多行）
    * Delete multiple rows（删除多行）
    * Update multiple rows（更新多行）
    * Create a row（创建一行）
    * Delete a row（删除一行）
    * Get a row（获取一行）
    * Get many rows（获取多行）
    * Update a row（更新一行）
