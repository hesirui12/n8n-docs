# Dropbox 节点

> **大白话**：Dropbox 就是网盘。这个节点让你在 n8n 工作流里直接操作网盘文件：上传、下载、复制、移动、删除文件或文件夹，还能按关键词搜索文件。相当于给自动化流程装了一个「网盘遥控器」。

用 Dropbox 节点在 Dropbox 里自动化干活，并把 Dropbox 和其他应用串起来。n8n 内置支持 Dropbox 的大量功能，包括创建、下载、移动和复制文件与文件夹。

本页面列出了 Dropbox 节点支持的所有操作，以及更多资源的链接。

## 支持的操作

* File（文件）
    * Copy a file（复制文件）
    * Delete a file（删除文件）
    * Download a file（下载文件）
    * Move a file（移动文件）
    * Upload a file（上传文件）
* Folder（文件夹）
    * Copy a folder（复制文件夹）
    * Create a folder（创建文件夹）
    * Delete a folder（删除文件夹）
    * Return the files and folders in a given folder（返回某个文件夹里的文件和子文件夹列表）
    * Move a folder（移动文件夹）
* Search（搜索）
    * Query（查询）
