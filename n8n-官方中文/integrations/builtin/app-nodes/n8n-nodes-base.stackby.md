{% hint style="info" %}
**大白话**：Stackby 是一个「表格 + 数据库」工具，类似 Airtable——用表格管理数据，还能跟很多应用联动。这个节点可以帮你：往表格里追加记录（Append）、删除记录（Delete）、列出记录（List）、读取记录（Read）。适合做简单的数据收集、表单入表、数据同步。
{% endhint %}

# Stackby 节点

使用 Stackby 节点来自动化你在 Stackby 中的工作，并把它与其它应用集成。n8n 内置支持 Stackby 的大量功能，包括追加、删除、列出和读取。

在本页你可以看到 Stackby 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Stackby 凭证](../credentials/stackby.md)。
{% endhint %}

## 操作

- Append（追加记录）
- Delete（删除记录）
- List（列出记录）
- Read（读取记录）
