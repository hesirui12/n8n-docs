# Emelia 节点

> **大白话**：Emelia 是自动发冷邮件（销售邮件）的工具。这个节点让你在 n8n 里创建/管理邮件营销活动（Campaign），并把联系人加进名单列表。

用 Emelia 节点在 Emelia 里自动化干活，并把 Emelia 和其他应用串起来。n8n 内置支持 Emelia 的大量功能，包括创建营销活动、把联系人加入列表。

本页面列出了 Emelia 节点支持的所有操作，以及更多资源的链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何配置认证，请参考 [Emelia 凭据](../credentials/emelia.md)。
{% endhint %}

## 支持的操作

* Campaign（营销活动）
    * Add Contact（添加联系人）
    * Create（创建）
    * Get（获取单个）
    * Get All（获取全部）
    * Pause（暂停）
    * Start（启动）
* Contact List（联系人列表）
    * Add（添加）
    * Get All（获取全部）
