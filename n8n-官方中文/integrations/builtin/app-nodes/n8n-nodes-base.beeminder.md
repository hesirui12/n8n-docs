# Beeminder 节点

> 💡 **大白话**：Beeminder 是一个「目标打卡」应用：你先立下一个目标（比如每天运动），它会把你的数据记录成「数据点」，如果没达标就要罚钱。用这个节点，你可以在 n8n 里自动给某个目标添加、删除、更新数据点，不用自己写代码。

使用 Beeminder 节点自动化 Beeminder 中的工作，并将 Beeminder 与其他应用集成。n8n 内置支持大量 Beeminder 功能，包括创建、删除和更新数据点。

本页列出了 Beeminder 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Beeminder 凭据](../credentials/beeminder.md)。
{% endhint %}

## 支持的操作（Operations）

**data point（数据点）**
- Create data point for a goal（为一个目标创建数据点）
- Delete a data point（删除数据点）
- Get all data points for a goal（获取一个目标的全部数据点）
- Update a data point（更新数据点）
