{% hint style="info" %}
**大白话**：Agile CRM 是一款轻量级 CRM（客户关系管理）软件，管客户、公司、交易。这个节点让你在 n8n 里直接增删改查公司（Company）、联系人（Contact）和交易（Deal）。常用场景：网站表单提交后自动创建联系人，销售谈成后自动把 Deal 状态更新。
{% endhint %}

# Agile CRM 节点

使用 Agile CRM 节点来自动化你在 Agile CRM 中的工作，并把它与其它应用集成。n8n 内置支持 Agile CRM 的大量功能，包括创建、获取、更新、删除公司、合同和交易。

在本页你可以看到 Agile CRM 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Agile CRM 凭证](../credentials/agilecrm.md)。
{% endhint %}

（官方此处嵌入了「如何开始使用应用节点」的通用说明组件，此处从略。）

## 操作

* Company（公司）
    * Create a new company（创建公司）
    * Delete a company（删除公司）
    * Get a company（获取公司）
    * Get all companies（获取全部公司）
    * Update company properties（更新公司属性）
* Contact（联系人）
    * Create a new contact（创建联系人）
    * Delete a contact（删除联系人）
    * Get a contact（获取联系人）
    * Get all contacts（获取全部联系人）
    * Update contact properties（更新联系人属性）
* Deal（交易）
    * Create a new deal（创建交易）
    * Delete a deal（删除交易）
    * Get a deal（获取交易）
    * Get all deals（获取全部交易）
    * Update deal properties（更新交易属性）
