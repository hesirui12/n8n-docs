{% hint style="info" %}
**大白话**：Xero 是一个「云端会计软件」——记账、开发票、管账单都在里面。这个节点可以帮你：管理联系人（Contact，即客户/供应商）和发票（Invoice）的增删改查。适合做财务自动化，比如订单来了自动开发票、自动同步客户信息。
{% endhint %}

# Xero 节点

使用 Xero 节点来自动化你在 Xero 中的工作，并把它与其它应用集成。n8n 内置支持 Xero 的大量功能，包括创建、更新和获取联系人与发票。

在本页你可以看到 Xero 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Xero 凭证](../credentials/xero.md)。
{% endhint %}

## 操作

* Contact（联系人）
    * Create a contact（创建联系人）
    * Get a contact（获取联系人）
    * Get all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Invoice（发票）
    * Create a invoice（创建发票）
    * Get a invoice（获取发票）
    * Get all invoices（获取全部发票）
    * Update a invoice（更新发票）
