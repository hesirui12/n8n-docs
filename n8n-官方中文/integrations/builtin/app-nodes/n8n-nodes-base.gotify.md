# Gotify 节点

> 💡 **大白话**：Gotify 是一个开源的「自建推送服务」，相当于自己搭一个推送通道，往自己的手机 App 上发通知。用这个节点，n8n 可以在工作流出问题或完成时自动推送一条消息到你的手机，完全自己掌控、不依赖第三方。

使用 Gotify 节点自动化 Gotify 中的工作，并将 Gotify 与其他应用集成。n8n 内置支持大量 Gotify 功能，包括创建、删除和获取消息。

本页列出了 Gotify 节点支持的操作，以及更多资源链接。
