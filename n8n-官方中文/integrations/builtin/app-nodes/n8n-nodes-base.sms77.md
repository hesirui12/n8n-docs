{% hint style="info" %}
**大白话**：seven（原 sms77）是一个「短信 / 语音通话服务商」——专门帮你发短信、打语音电话。这个节点可以帮你：发短信（SMS）、把文字转成语音并打电话给指定号码。适合做验证码通知、告警短信、自动外呼等场景。
{% endhint %}

# seven 节点

使用 seven 节点来自动化你在 seven 中的工作，并把它与其它应用集成。n8n 内置支持 seven 的大量功能，包括发送短信，以及把文本转成语音。

在本页你可以看到 seven 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [seven 凭证](../credentials/sms77.md)。
{% endhint %}

## 操作

* SMS（短信）
    * Send SMS（发送短信）
* Voice Call（语音通话）
    * Converts text to voice and calls a given number（把文字转成语音，并拨打指定号码）
