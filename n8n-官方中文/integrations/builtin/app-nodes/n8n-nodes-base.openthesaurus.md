{% hint style="info" %}
**大白话**：OpenThesaurus 是一个开源的德语在线同义词词典（就是查「近义词」的工具）。这个节点让你在 n8n 里直接查某个德语单词的同义词——注意它只支持德语，适合做德语内容处理类的工作流。
{% endhint %}

# OpenThesaurus 节点

使用 OpenThesaurus 节点来自动化你在 OpenThesaurus 中的工作，并把它与其它应用集成。n8n 支持德语单词的同义词查询。

在本页你可以看到 OpenThesaurus 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

OpenThesaurus 节点不需要认证。

{% endhint %}

## 操作

* Get synonyms for a German word in German（用德语查询一个德语单词的同义词）
