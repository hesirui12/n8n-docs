{% hint style="info" %}
**大白话**：MailerLite 是另一个邮件营销平台，主打便宜好用（免费额度大），适合小团队和独立站长。这个节点主要就是管「订阅用户」（Subscriber）：用户在别处留了邮箱 → 自动加进 MailerLite 名单 → 定时发营销邮件，全流程自动化。
{% endhint %}

# MailerLite 节点

使用 MailerLite 节点来自动化你在 MailerLite 中的工作，并把它与其它应用集成。n8n 内置支持 MailerLite 的大量功能，包括创建、更新、删除和获取订阅用户（subscriber）。

在本页你可以看到 MailerLite 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [MailerLite 凭证](../credentials/mailerlite.md)。
{% endhint %}

## 操作

* Subscriber（订阅用户）
    * Create a new subscriber（创建新订阅用户）
    * Get an subscriber（获取订阅用户）
    * Get all subscribers（获取全部订阅用户）
    * Update an subscriber（更新订阅用户）
