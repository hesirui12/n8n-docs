{% hint style="info" %}
**大白话**：Humantic AI 是一家用 AI 做「买家画像 / 人物性格分析」的服务，可以根据公开信息分析一个人的性格和沟通风格，帮助销售更好地跟客户打交道。这个节点功能很简单，就三件事：创建画像（Create a profile）、获取画像（Retrieve a profile）、更新画像（Update a profile）。
{% endhint %}

# Humantic AI 节点

使用 Humantic AI 节点来自动化你在 Humantic AI 中的工作，并把它与其它应用集成。n8n 内置支持 Humantic AI 的大量功能，包括创建、获取和更新画像（Profile）。

在本页你可以看到 Humantic AI 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Humantic AI 凭证](../credentials/humanticai.md)。
{% endhint %}

## 操作

* Profile（画像）
    * Create a profile（创建画像）
    * Retrieve a profile（获取画像）
    * Update a profile（更新画像）
