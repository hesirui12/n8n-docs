# GetResponse 节点

> **大白话**：GetResponse 是邮件营销平台（群发邮件、自动营销）。这个节点让你在 n8n 里自动管理订阅联系人：新建、删除、查询单个/全部、修改联系人属性（比如改订阅状态、标签等）。

用 GetResponse 节点在 GetResponse 里自动化干活，并把 GetResponse 和其他应用串起来。n8n 内置支持 GetResponse 的大量功能，包括创建、更新、删除和获取联系人。

本页面列出了 GetResponse 节点支持的所有操作，以及更多资源的链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何配置认证，请参考 [GetResponse 凭据](../credentials/getresponse.md)。
{% endhint %}

## 支持的操作

* Contact（联系人）
    * Create a new contact（创建新联系人）
    * Delete a contact（删除联系人）
    * Get a contact（获取单个联系人）
    * Get all contacts（获取全部联系人）
    * Update contact properties（更新联系人属性）
