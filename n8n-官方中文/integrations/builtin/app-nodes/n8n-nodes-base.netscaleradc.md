# Netscaler ADC 节点

> 💡 **大白话**：Netscaler ADC（前身叫 Citrix ADC）是一款「应用交付控制器」，企业用它做负载均衡、流量管理。用这个节点，你可以让 n8n 自动创建和安装证书（Certificate）、上传/下载/删除文件（File），比如「证书快过期时自动换新证书」。

使用 Netscaler ADC 节点来自动化你在 Netscaler ADC 中的工作，并把它与其它应用集成。n8n 内置支持 Netscaler ADC 的大量功能，包括创建和安装证书及文件。

在本页你可以看到 Netscaler ADC 节点支持的全部操作列表，以及更多资源的链接。

## 操作（Operations）

* Certificate（证书）
	* Create（创建）
	* Install（安装）
* File（文件）
	* Delete（删除）
	* Download（下载）
	* Upload（上传）
