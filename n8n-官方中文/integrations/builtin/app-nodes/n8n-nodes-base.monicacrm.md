# Monica CRM 节点

> 💡 **大白话**：Monica CRM 是一个「个人关系管理」工具，帮你记录与家人、朋友、客户的联系（生日、通话、留言、待办等）。用这个节点，你可以让 n8n 自动增删改查活动（Activity）、通话（Call）、联系人（Contact）、任务（Task）、笔记（Note）等所有资料。

使用 Monica CRM 节点来自动化你在 Monica CRM 中的工作，并把它与其它应用集成。n8n 内置支持 Monica CRM 的大量功能，包括创建、更新、删除和获取活动、通话、合同、消息、任务和笔记。

在本页你可以看到 Monica CRM 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Monica CRM 凭证](../credentials/monicacrm.md)。
{% endhint %}
