{% hint style="info" %}
**大白话**：MessageBird（现在叫 Bird）是一个全球性的短信/语音/WhatsApp 通信服务商，主打给开发者用、覆盖面广。这个节点就两个功能：发短信（SMS）和查账户余额。典型用法：有人下单 → 自动给客户发一条确认短信。
{% endhint %}

# MessageBird 节点

使用 MessageBird 节点来自动化你在 MessageBird 中的工作，并把它与其它应用集成。n8n 内置支持 MessageBird 的大量功能，包括发送消息和获取余额（balance）。

在本页你可以看到 MessageBird 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [MessageBird 凭证](../credentials/messagebird.md)。
{% endhint %}

## 操作

* SMS（短信）
    * Send text messages (SMS)（发送文本短信）
* Balance（余额）
    * Get the balance（获取余额）
