# Dropcontact 节点

> **大白话**：Dropcontact 是帮你「补齐联系人信息」的工具（比如你有邮箱，它能补出姓名、电话、公司等）。这个节点让你在 n8n 里自动发起数据补全请求、查询补全结果。

用 Dropcontact 节点在 Dropcontact 里自动化干活，并把 Dropcontact 和其他应用串起来。n8n 内置支持 Dropcontact 的大量功能，包括获取联系人。

本页面列出了 Dropcontact 节点支持的所有操作，以及更多资源的链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何配置认证，请参考 [Dropcontact 凭据](../credentials/dropcontact.md)。
{% endhint %}

## 支持的操作

**Contact（联系人）**
- Enrich（补全联系人信息）
- Fetch Request（获取补全请求的结果）
