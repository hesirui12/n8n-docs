{% hint style="info" %}
**大白话**：Vonage 是一个「云通信平台」（前身是 Nexmo），提供短信、语音、视频通话等 API。目前这个节点只支持一件事：发短信（SMS）。适合做验证码短信、通知短信、营销短信的自动化发送。
{% endhint %}

# Vonage 节点

使用 Vonage 节点来自动化你在 Vonage 中的工作，并把它与其它应用集成。n8n 支持通过 Vonage 发送短信。

在本页你可以看到 Vonage 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Vonage 凭证](../credentials/vonage.md)。
{% endhint %}

## 操作

* SMS（短信）
    * Send（发送）
