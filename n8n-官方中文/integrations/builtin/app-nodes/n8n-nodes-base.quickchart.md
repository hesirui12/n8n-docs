{% hint style="info" %}
**大白话**：QuickChart 是一个在线图表生成服务，你把数据传给它，它就帮你生成一张图表图片。用这个节点，你可以在 n8n 里自动生成柱状图、折线图、饼图等图表，比如「把每日销售额数据自动画成一张饼图，然后发到群里」。
{% endhint %}

# QuickChart 节点

使用 QuickChart 节点来自动化你在 QuickChart 中的工作，并把它与其它应用集成。n8n 内置支持 QuickChart 的大量图表类型，包括柱状图（bar）、环形图（doughnut）、折线图（line）、饼图（pie）和极区图（polar）。

在本页你可以看到 QuickChart 节点支持的全部操作列表，以及更多资源的链接。

## 操作（Operations）

选择图表类型来创建图表：

* Chart Type（图表类型）
	* Bar Chart（柱状图）
	* Doughnut Chart（环形图）
	* Line Chart（折线图）
	* Pie Chart（饼图）
	* Polar Chart（极区图）
