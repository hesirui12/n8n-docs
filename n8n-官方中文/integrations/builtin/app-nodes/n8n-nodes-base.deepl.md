# DeepL 节点

> **大白话**：DeepL 是公认翻译质量很高的在线翻译服务。这个节点让 n8n 能自动调用 DeepL 翻译——把工作流里的任意文本翻译成目标语言。举例：客户提交的多语言工单，工作流先自动翻译成中文再交给客服处理；或者把后台商品描述自动翻译成多国语言发布。

使用 DeepL 节点可以自动化处理 DeepL 里的工作，并让 DeepL 与其他应用程序互通。n8n 内置支持 DeepL 的众多功能，包括语言翻译等。

本页列出了 DeepL 节点支持的操作清单，以及更多资源的链接。
