# Mocean 节点

> 💡 **大白话**：Mocean 是一个「短信和语音消息」服务商。用这个节点，你可以让 n8n 自动发短信或语音消息，比如「订单发货了，自动给客户发条短信通知」。

使用 Mocean 节点来自动化你在 Mocean 中的工作，并把它与其它应用集成。n8n 内置支持 Mocean 的大量功能，包括发送短信和语音消息。

在本页你可以看到 Mocean 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Mocean 凭证](../credentials/mocean.md)。
{% endhint %}

## 操作（Operations）

* SMS（短信）
    * Send SMS/Voice message（发送短信/语音消息）
* Voice（语音）
    * Send SMS/Voice message（发送短信/语音消息）
