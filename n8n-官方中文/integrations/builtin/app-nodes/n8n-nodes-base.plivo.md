{% hint style="info" %}
**大白话**：Plivo 是云通信服务商（提供打电话、发短信的 API，类似 Twilio）。这个节点让你在 n8n 里直接打电话、发短信/彩信：发起语音通话（Make a voice call）、发送 MMS（仅限美国/加拿大）、发送 SMS——适合做「订单状态短信通知」「自动语音提醒」之类的自动化。
{% endhint %}

# Plivo 节点

使用 Plivo 节点来自动化你在 Plivo 中的工作，并把它与其它应用集成。n8n 内置支持 Plivo 的大量功能，包括拨打电话和发送 SMS/MMS 短信。

在本页你可以看到 Plivo 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Plivo 凭证](../credentials/plivo.md)。
{% endhint %}

## 操作

* Call（通话）
    * Make a voice call（发起语音通话）
* MMS（彩信）
    * Send an MMS message (US/Canada only)（发送 MMS 彩信（仅限美国/加拿大））
* SMS（短信）
    * Send an SMS message.（发送 SMS 短信）
