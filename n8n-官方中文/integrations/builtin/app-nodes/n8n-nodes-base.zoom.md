{% hint style="info" %}
**大白话**：Zoom 是主流的「视频会议软件」。这个节点目前只做一件事：管理会议（Meeting）——创建、删除、获取、获取全部、更新会议。适合做会议自动化，比如有人预约就自动建 Zoom 会议、把会议链接自动发给参会者。
{% endhint %}

# Zoom 节点

使用 Zoom 节点来自动化你在 Zoom 中的工作，并把它与其它应用集成。n8n 内置支持 Zoom 的大量功能，包括创建、获取、删除和更新会议。

在本页你可以看到 Zoom 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Zoom 凭证](../credentials/zoom.md)。
{% endhint %}

## 操作

* Meeting（会议）
    * Create a meeting（创建会议）
    * Delete a meeting（删除会议）
    * Retrieve a meeting（获取会议）
    * Retrieve all meetings（获取全部会议）
    * Update a meeting（更新会议）
