**大白话**：WordPress 是世界上使用最广的开源建站/博客系统。这个节点可以帮你：管理文章（Post）、页面（Pages）、用户（User）的增删改查。适合做内容自动化，比如把新内容自动发布成文章、批量更新文章、自动创建用户等。
{% endhint %}

# WordPress 节点

使用 WordPress 节点来自动化你在 WordPress 中的工作，并把它与其它应用集成。n8n 内置支持 WordPress 的大量功能，包括创建、更新和获取文章与用户。

在本页你可以看到 WordPress 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [WordPress 凭证](../credentials/wordpress.md)。
{% endhint %}

## 操作

* Post（文章）
    * Create a post（创建文章）
    * Get a post（获取文章）
    * Get all posts（获取全部文章）
    * Update a post（更新文章）
* Pages（页面）
    * Create a page（创建页面）
    * Get a page（获取页面）
    * Get all pages（获取全部页面）
    * Update a page（更新页面）
* User（用户）
    * Create a user（创建用户）
    * Get a user（获取用户）
    * Get all users（获取全部用户）
    * Update a user（更新用户）
