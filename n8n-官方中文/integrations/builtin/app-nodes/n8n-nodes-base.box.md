# Box 节点

> 💡 **大白话**：Box 是一款「企业云网盘」，用来集中存文件和文件夹，方便团队共享。用这个节点，你可以在 n8n 里自动上传、下载、复制、删除、搜索、分享文件和文件夹，不用自己写代码。

使用 Box 节点自动化 Box 中的工作，并将 Box 与其他应用集成。n8n 内置支持大量 Box 功能，包括创建、复制、删除、搜索、上传和下载文件与文件夹。

本页列出了 Box 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Box 凭据](../credentials/box.md)。
{% endhint %}
 

## 支持的操作（Operations）

* File（文件）
    * Copy a file（复制文件）
    * Delete a file（删除文件）
    * Download a file（下载文件）
    * Get a file（获取文件）
    * Search files（搜索文件）
    * Share a file（分享文件）
    * Upload a file（上传文件）
* Folder（文件夹）
    * Create a folder（创建文件夹）
    * Get a folder（获取文件夹）
    * Delete a folder（删除文件夹）
    * Search files（搜索文件）
    * Share a folder（分享文件夹）
    * Update folder（更新文件夹）
