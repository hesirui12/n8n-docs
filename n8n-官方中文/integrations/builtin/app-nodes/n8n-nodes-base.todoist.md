{% hint style="info" %}
**大白话**：Todoist 是知名待办事项（To-Do）应用。这个节点让你在 n8n 里管理它的任务（Task）：新建、关闭、删除、查询、重开、更新都可以。常用场景：收到新工单自动在 Todoist 建一条任务；或者每天把过期的任务自动标记完成。
{% endhint %}

# Todoist 节点

使用 Todoist 节点来自动化你在 Todoist 中的工作，并把它与其它应用集成。n8n 内置支持 Todoist 的大量功能，包括创建、更新、删除和获取任务（Task）。

在本页你可以看到 Todoist 节点支持的全部操作列表，以及更多资源的链接。

{% hint style="info" %}
**凭证（Credentials）**

关于如何设置认证，请参考 [Todoist 凭证](../credentials/todoist.md)。
{% endhint %}

（官方此处嵌入了「如何开始使用应用节点」的通用说明组件，此处从略。）

## 操作

* Task（任务）
    * Create a new task（创建新任务）
    * Close a task（关闭任务）
    * Delete a task（删除任务）
    * Get a task（获取单个任务）
    * Get all tasks（获取全部任务）
    * Reopen a task（重新打开任务）
    * Update a task（更新任务）
