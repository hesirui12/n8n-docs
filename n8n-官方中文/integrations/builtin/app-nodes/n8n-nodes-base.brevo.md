# Brevo 节点

> 💡 **大白话**：Brevo（原 Sendinblue）是一款「邮件营销平台」，用来管理联系人、发营销邮件。用这个节点，你可以在 n8n 里自动增删改查联系人、管理联系人属性、发送邮件和模板邮件、管理发件人，不用自己写代码。

使用 Brevo 节点自动化 Brevo 中的工作，并将 Brevo 与其他应用集成。n8n 内置支持大量 Brevo 功能，包括创建、更新、删除和获取联系人、属性，以及发送邮件。

本页列出了 Brevo 节点支持的操作，以及更多资源链接。

{% hint style="info" %}
**凭据（Credentials）**

关于如何设置认证，请参考 [Brevo 凭据](../credentials/brevo.md)。
{% endhint %}

## 支持的操作（Operations）

* Contact（联系人）
    * Create（创建）
    * Create or Update（创建或更新）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Contact Attribute（联系人属性）
    * Create（创建）
    * Delete（删除）
    * Get All（获取全部）
    * Update（更新）
* Email（邮件）
    * Send（发送）
    * Send Template（发送模板邮件）
* Sender（发件人）
    * Create（创建）
    * Delete（删除）
    * Get All（获取全部）
