# 使用社区节点 / Using community nodes

> 💡 **大白话**：装好社区节点后，它用起来和官方节点一模一样——直接在节点面板搜索就能找到，只是多了一个「包（Package）」图标标明来源。

## 把社区节点添加到工作流 / Adding community nodes to your workflow

安装社区节点后，你可以像使用其他任何节点一样使用它。n8n 会在**节点面板（Nodes panel）**的搜索结果中显示该节点，并用一个「包（Package）」图标 <img src="../../.gitbook/assets/package.png" alt="Package icon" data-size="line"> 标记社区节点。

## 重名的社区节点 / Community nodes with duplicate names

多个社区节点有可能重名。如果你在工作流里用了两个同名的节点，除非它们的图标不同，否则看起来会一模一样——添加时留意区分。
