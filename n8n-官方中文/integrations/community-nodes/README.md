# 社区节点 / Community nodes

> 💡 **大白话**：n8n 内置 400+ 官方节点，但全世界的开发者还能把自己做的节点发布到 npm，供大家免费安装使用——这些就叫**社区节点（Community Nodes）**。你可以把它理解成「手机应用商店里的第三方 App」：好用，但要自己判断安不安全。

社区节点（Community Nodes）是由社区成员开发和维护的节点。本板块教你：如何使用、如何排查问题、如何自己开发，以及需要注意的安全风险。
