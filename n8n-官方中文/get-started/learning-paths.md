## 官方资源 / Official resources

- **互动课程**：n8n 官方提供带练习、测验和真实工作流构建的互动课程（[learn.n8n.io](https://learn.n8n.io)）

- **社区论坛**：[community.n8n.io](https://community.n8n.io) 提问求助

## 小白建议 / Tips for beginners

1. **先做后学**：跟着教程做出第一个工作流，比先读完全部概念有效得多
2. **多用模板**：导入官方模板看别人怎么搭，是最快的学习路径
3. **从手动触发开始**：先手动执行调试，确认无误再发布为定时/Webhook 自动运行
4. **善用表达式预览**：在表达式输入框里能看到实时计算结果，边写边验证
5. **遇到问题先看执行记录**：Failed 状态 + Debug in editor 能定位大多数问题
