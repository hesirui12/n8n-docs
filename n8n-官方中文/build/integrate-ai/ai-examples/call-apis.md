# 调用 API（Call APIs）

使用 n8n 把任何 API[^1] 的数据带给你的 AI。这个工作流使用 [Chat Trigger](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/core-nodes/n8n-nodes-langchain.chattrigger) 提供聊天界面，并使用 [Call n8n Workflow Tool](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.toolworkflow) 调用第二个工作流来访问 API。第二个工作流会利用 AI 功能，根据用户的提问来优化 API 请求。

{% hint style="info" %}
**这个示例讲了什么？——大白话版**

很多人想让 AI 回答问题时能「查实时数据」。比如用户问「今天有什么适合一个人做的学习类活动？」，AI 自己不知道答案，但它可以去调用一个专门提供活动建议的 API（接口）来拿到真实数据。

本例用**两个工作流**配合完成这件事：

1. **主工作流**：一个 AI Agent，配上 Chat Trigger（聊天触发器）接收用户提问；
2. **子工作流**（通过 Call n8n Workflow Tool 接入）：里面有一条 Basic LLM Chain（基础 LLM 链），先让 AI 把用户的话「翻译」成 API 需要的参数（活动类型、参与人数），再用 HTTP Request 节点调用 API，最后把结果返回给 AI Agent。

这样一来，AI 就成了一个「会自己查资料再回答」的助手。下方展示的就是这两个工作流的完整结构。
{% endhint %}

## 核心特性（Key features）

这个工作流使用了：

* [Chat Trigger](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/core-nodes/n8n-nodes-langchain.chattrigger)（聊天触发器）：启动你的工作流并响应用户的聊天交互。该节点提供了一个可自定义的聊天界面。
* [Agent](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/root-nodes/n8n-nodes-langchain.agent)（智能体）：AI 工作流中的关键组件。Agent 与工作流的其他组件交互，并决定该使用哪些工具。
* [Call n8n Workflow Tool](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.toolworkflow)（调用 n8n 工作流工具）：把 n8n 工作流当作自定义工具插进来。在 AI 中，工具是 AI 用来与世界交互的接口（在本例中，就是你的工作流提供的数据）。AI 模型使用该工具来获取超出其内置数据集的信息。
* 一条 [Basic LLM Chain](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/root-nodes/n8n-nodes-langchain.chainllm)（基础 LLM 链），搭配 [Auto-fixing Output Parser](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.outputparserautofixing)（自动修复输出解析器）和 [Structured Output Parser](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.outputparserstructured)（结构化输出解析器）：用来读取用户的提问，并根据用户输入设置 API 调用的参数。

{% hint style="info" %}
**什么是 Output Parser（输出解析器）？**

大语言模型输出的是一大段「文字」，但程序往往需要「结构化的数据」（比如 JSON 对象）。输出解析器的作用就是把 AI 说的话整理成固定格式。

- **Structured Output Parser（结构化输出解析器）**：按你定义的 JSON Schema（数据格式模板），把 AI 的输出整理成对应的 JSON。
- **Auto-fixing Output Parser（自动修复输出解析器）**：如果 AI 输出的格式不对（比如漏了字段），它会自动让 AI 再改一次，直到格式正确为止。

本例中子工作流用它们把「活动类型、参与人数」从用户的话里提取成 API 需要的参数。
{% endhint %}
