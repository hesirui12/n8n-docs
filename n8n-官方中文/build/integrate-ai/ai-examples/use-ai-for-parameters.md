# 让 AI 指定工具参数（Let AI specify the tool parameters）

在配置连接到 **Tools Agent**（工具智能体）的工具[^1]时，很多参数可以由 AI 模型自己填写。AI 模型会利用**任务中的上下文**（比如用户刚刚说的话）和**其他已连接工具的信息**，来填上合适的细节。

{% hint style="info" %}
**这篇讲什么？——大白话版**

工具（tool）本质上就是一个「函数」，调用它时需要传一些参数。比如「发送邮件」这个工具，需要知道：发给谁（to）、主题（subject）、正文（body）。

以前这些参数得你手动填，或者用表达式从数据里取。而现在：**你可以让 AI 自己决定填什么**。用户在聊天里说「帮我给 jane@example.com 发封邮件」，AI 就能自动从这句话里把收件人、主题、正文提取出来填进工具参数里。

n8n 提供了两种「让 AI 填参数」的方式，你可以随时切换：
1. 点一下工具参数旁边的「星星」按钮，让 AI Agent 自动帮你生成表达式；
2. 手动用 `$fromAI()` 函数，自定义控制 AI 怎么填。
{% endhint %}

有两种方式可以做到这一点，而且你可以在两者之间随意切换。

## 让模型填写参数（Let the model fill in the parameter）

工具编辑对话框中，每个适用的参数字段末尾都有一个额外的按钮（星星图标）：

![image showing stars icon to the right of parameter field](../../.gitbook/assets/ai-stars.png)

激活这个按钮后，[AI Agent](#user-content-fn-2)[^2] 会为你自动填写表达式，无需你再做任何输入。字段本身会填充一条消息，说明「该参数已由模型自动定义」。

如果你想自己定义这个参数，点击此框中的 **X** 即可恢复为用户自定义值。注意：此时「expression（表达式）」字段里会包含这个功能自动生成的表达式，你可以继续编辑它来添加额外细节，方法见下一节。

{% hint style="warning" %}
**注意！**

激活此功能会**覆盖**你可能已经手动添加的任何定义。如果之前已经填好了值，点星星之前建议先复制一份存好。
{% endhint %}

## 使用 `$fromAI()` 函数（Use the `$fromAI()` function）

`$fromAI()` 函数使用 AI 为连接到 [Tools AI agent](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/root-nodes/n8n-nodes-langchain.agent/tools-agent)（工具智能体）的工具动态填充参数。

{% hint style="info" %}
**仅适用于工具**

`$fromAI()` 函数**只**适用于连接到 AI Agent 节点的工具。它不能与 [Code](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.toolcode)（代码）工具一起使用，也不能用于其他非工具型集群子节点。
{% endhint %}

要使用 `$fromAI()` 函数，请用必需的 `key` 参数调用它：

```javascript
{{ $fromAI('email') }}
```

`key` 参数和 `$fromAI()` 函数的其他参数**并不是对现有值的引用**（不会去读取某个变量）。相反，可以把这些参数理解为「**提示（hints）**」——它们是给 AI 模型的线索，AI 会根据这些线索去找正确的数据填进来。

{% hint style="info" %}
**举个例子——大白话版**

如果你把 key 取名叫 `email`，AI 模型会去它的上下文里、其他工具里和输入数据里寻找邮箱地址。在聊天工作流中，如果它到处都找不到邮箱，**它可能会直接开口向用户要**：「请问您的邮箱地址是？」——是的，AI 会主动问用户要信息。

你还可以额外传入 `description`（描述）等参数，给 AI 模型更多上下文，帮助它理解这个参数应该填什么。
{% endhint %}

### 参数（Parameters）

`$fromAI()` 函数接受以下参数：

| 参数（Parameter） | 类型（Type） | 是否必填（Required?） | 说明（Description） |
| --------- | ---- | --------- | ----------- |
| `key` | string | ✅ | 表示参数键或名称的字符串。长度必须在 1 到 64 个字符之间，且只能包含大小写字母、数字、下划线（`_`）和连字符（`-`）。 |
| `description` | string | ❌ | 描述这个参数的字符串。给 AI 的提示越清楚，AI 填得越准。 |
| `type` | string | ❌ | 指定数据类型的字符串。可以是 `string`、`number`、`boolean` 或 `json`（默认为 `string`）。 |
| `defaultValue` | any | ❌ | 该参数的默认值。当 AI 实在找不到合适内容时，会使用这个值兜底。 |

{% hint style="info" %}
**四个参数怎么用？——大白话版**

- **key（键/名字）**：必填。给这个参数起个名字，相当于告诉 AI「我要的是一个叫 xx 的数据」。
- **description（描述）**：选填。用一句话说明这个参数是什么，AI 理解更准确。
- **type（类型）**：选填。告诉 AI 填进来的是文字、数字、布尔值还是 JSON。默认是文字。
- **defaultValue（默认值）**：选填。AI 找不到数据时的「保底答案」，避免参数空缺导致工具报错。
{% endhint %}

### 示例（Examples）

例如，你可以用下面的 `$fromAI()` 表达式，动态填充一个「名字」字段：

```javascript
$fromAI("name", "The commenter's name", "string", "Jane Doe")
```

如果你不需要那些可选参数，可以简化成这样：

```javascript
$fromAI("name")
```

要动态填充「库存商品数量」，你可以使用这样的 `$fromAI()` 表达式：

```javascript
$fromAI("numItemsInStock", "Number of items in stock", "number", 5)
```

如果你只想用模型的动态值填充字段的**一部分**，你也可以把它用在普通表达式里。例如，你想让模型填写电子邮件的 `subject`（主题）参数，但总希望在生成值前面加上固定前缀「Generated by AI:」，可以使用以下表达式：

```javascript
Generated by AI: {{ $fromAI("subject") }}
```

{% hint style="info" %}
**最后一个例子说明**

`$fromAI()` 可以嵌在普通文本里使用。这里的结果是：AI 生成主题（比如「Meeting tomorrow」），前面自动加上「Generated by AI:」，最终填进 `subject` 字段的值就是「Generated by AI: Meeting tomorrow」。这样每条由 AI 生成的邮件主题都有统一标记。
{% endhint %}
