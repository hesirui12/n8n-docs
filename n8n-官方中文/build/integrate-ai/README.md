# 集成 AI（Integrate AI）

n8n 让你可以构建 AI 工作流（AI workflow）：连接不同的 LLM 提供商（provider），例如 OpenAI、Anthropic 和 Google；给 AI 添加工具（tool）和记忆（memory）；甚至在一个工作流里组合多个模型一起使用。
