# 转换数据 / Transform data

{% hint style="info" %}
**大白话**：这个栏目是「转换数据」的目录页。所谓「转换（transform）」，就是**改变数据的形态**——比如把数据从一种格式变成另一种格式、过滤掉不需要的记录、把多行合并成一行、给数据加一列计算结果等等。n8n 提供了多种「转换」的手段（表达式、代码节点、AI 转换节点、专门的转换节点……），下面这几个子页面就是教你怎么用它们的。先把「转换数据的各种方法」看完，再按需深入。
