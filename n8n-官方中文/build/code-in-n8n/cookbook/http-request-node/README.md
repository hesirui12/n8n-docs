# n8n HTTP 请求节点使用示例 <a href="#examples-using-n8ns-http-request-node" id="examples-using-n8ns-http-request-node"></a>

HTTP 请求节点是 n8n 里最万能的节点之一。用这个节点发 HTTP 请求，就能从任何带 REST API 的应用或服务中查询数据。

节点设置信息参见 [HTTP Request](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/builtin/core-nodes/n8n-nodes-base.httprequest)。
