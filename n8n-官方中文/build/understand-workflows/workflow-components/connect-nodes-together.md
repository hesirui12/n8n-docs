# 连接节点 / Connect nodes together

连接（Connection）会在节点之间建立一条链接，让数据能够沿着工作流流动。两个节点之间的连接，会把一个节点的输出数据，传给另一个节点的输入。

![Example of creating and deleting a connection](../../.gitbook/assets/example.gif)

## 创建连接 / Create a connection

要在两个节点之间创建连接：选中节点右侧的灰色小圆点（或者 **Add node**（添加节点）<img src="../../.gitbook/assets/add-node-small (1).png" alt="Add node icon" data-size="line">），然后把箭头拖到下一个节点左侧的灰色小矩形上，松手即可。

{% hint style="info" %}
**大白话**：连线就是"把 A 的结果递给 B"。从节点右侧的小圆点拖一条线到下一个节点左侧的矩形，数据就从 A 流到 B 了。
{% endhint %}

## 删除连接 / Delete a connection

把鼠标悬停在连接线上，然后点击 **Delete**（删除）<img src="../../.gitbook/assets/delete-connector.png" alt="Delete connector icon" data-size="line">。
