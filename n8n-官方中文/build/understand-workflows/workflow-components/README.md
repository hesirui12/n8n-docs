# 工作流组件 / Workflow components

本板块包含以下内容：

* [节点 / Nodes](work-with-nodes.md)：集成（integration，也就是"连接外部软件或服务"的能力）和操作（operation，也就是对数据执行的具体动作）。
* [连接 / Connections](connect-nodes-together.md)：节点连接器，也就是把数据从一个节点传递到下一个节点的"管道"。
* [便签 / Sticky notes](add-notes-and-documentation.md)：为你的工作流添加注释和说明文档，方便自己和别人看懂。
* [画布分组 / Canvas Groups](canvas-groups.md)：把相关的节点组织到一起，让大型工作流更清晰易读。

{% hint style="info" %}
**大白话**：如果把工作流比作一条"流水线"，那么：**节点**就是流水线上的每一台机器（负责干活的），**连接**就是机器之间传送物料的传送带（负责传数据的），**便签**就是贴在机器旁的便利贴（负责写说明的），而**画布分组**就是把几台相关的机器圈进一个区域、贴个标签（负责整理收纳的）。
{% endhint %}
