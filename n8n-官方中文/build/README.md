# 构建 / Build

在 n8n 中构建工作流，从第一份草稿到正式生产。

使用本板块学习：工作流基础、数据处理、流程逻辑、代码和 AI。

> 💡 **大白话**：这一整个「构建 Build」板块就是教你**怎么搭工作流**——从认识积木（节点）、学会连线，到处理数据、写逻辑、玩 AI，一步步把你从新手带到能独立做自动化。
