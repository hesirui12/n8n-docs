# 构建你的节点（Build a node）

本节提供关于如何构建节点（node）的教程，涵盖以下内容：

* [教程：构建声明式（declarative-style）节点](tutorial-build-a-declarative-style-node.md)
* [参考（Reference）](reference/README.md)资料，内容包括[文件结构](../plan-your-node/choose-node-file-structure.md)、[基础（base）](reference/base-files/README.md)、[codex](reference/codex-files.md) 和[凭据（credentials）](reference/credentials-files.md)文件的参数定义、[节点 UI 元素](reference/node-ui-elements.md)等。

即将推出：

* 更多教程
* 修订后的标准指南

{% hint style="info" %}
**小白提示**：什么是「节点」？在 n8n 里，节点就是工作流中的一个小积木（比如「发送邮件」「读取数据库」）。本节教你怎么**自己写一个全新的节点**，让你能把任何没有现成积木的服务接进 n8n。整个学习路径是：先看教程（怎么一步步做），再查参考（每个配置项是什么意思）。
{% endhint %}
