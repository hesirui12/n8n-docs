# 部署一个节点（Deploy a node）

本节包含如何部署和分享你的节点的详细信息。

你可以选择：

* [把你的节点提交到社区节点仓库](submit-community-nodes.md)。这会让它被所有人使用，并且你可以像使用任何其他社区节点一样[安装和使用它](https://app.gitbook.com/s/BKcbOzIWja8NfqKDcqHc/community-nodes/installation-and-management)。这是在 n8n 云（cloud）上使用自定义节点的唯一方式。
* 把节点作为[私有节点](install-private-nodes.md)安装到你的 n8n 实例中。

{% hint style="info" %}
**小白提示：两种方式怎么选？**

- **提交到社区仓库**：让全世界都能用你的节点。适合你做得比较成熟、想分享/想被 n8n 官方审核认证的节点。注意：如果你用的是 n8n 云（Cloud）版本，**只有这一条路**——云上没法装私有节点。
- **私有节点**：只装在你自己的 n8n 实例（比如公司自托管的服务器、本地 Docker）里，不对外发布到 npm。适合公司内部专用、不想公开的节点。
{% endhint %}
