# 配置示例 / Configuration examples

本部分包含如何配置 n8n 以解决特定使用场景（use cases）的示例。

{% hint style="info" %}
**大白话**：这一整个章节收集了很多「配置 n8n」的实际例子，每个例子都针对一个具体需求——比如设置时区、配置工作流超时、把 n8n 放到反向代理后面、开启监控指标（Prometheus）、给 Code 节点开放外部模块等等。你不需要从头到尾读完，只要找到自己遇到的问题，照着对应的示例配置即可。如果你是小白，遇到不懂的概念（比如环境变量、Docker、反向代理），可以先看对应例子开头的「大白话」解释。
{% endhint %}
