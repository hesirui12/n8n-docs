# Cloud IP 地址（Cloud IP addresses）

{% hint style="warning" %}
**Cloud 的 IP 地址会随时变化，且不做任何预告**

n8n 无法保证固定的出口 IP（static source IP），因为 Cloud 运行在动态的云服务商环境中，会根据需求弹性扩缩容基础设施。因此，当你与 n8n 建立出入连接时，应该使用**强身份验证（strong authentication）**和**安全的传输协议（secure transport protocols）**（例如 HTTPS、SSH 等），而不是依赖 IP 白名单来保证安全。
{% endhint %}

**小白提示：这些 IP 有什么用？**

如果你在自己公司的服务器上部署了某些服务，并且只允许白名单 IP 访问（比如数据库、API 网关、内网服务等），就需要把上面这些 IP 加进白名单，n8n Cloud 才能正常访问它们。另外，「/32」表示某一个具体的 IP 地址，「/28」表示一小段连续的 IP 地址范围（共 16 个地址），加白名单时请原样填写，不要去掉后缀。
{% endhint %}

**国内访问提示**：以上 IP 属于海外云服务商（Azure）。如果你的业务系统也部署在国内云上，跨网络访问可能较慢或受限；请先确认你的防火墙与云安全组允许这些 IP 的入站访问，再进行白名单配置。
{% endhint %}
