# 使用 n8n Cloud（Use n8n Cloud）

n8n Cloud 是 n8n 官方提供的「托管服务」：你不需要自己买服务器、装环境、管升级，n8n 官方帮你把一切都运行在云端，你只需要打开浏览器登录使用即可。对小白来说，这是**上手最快、最省心**的方式。

{% hint style="info" %}
**小白提示**：简单理解，n8n Cloud 就像「租好的精装房」，而自托管（Self-hosted）是「买毛坯房自己装修」。Cloud 模式不用折腾服务器，上手极快；自托管更灵活、长期成本可能更低，但需要你自己维护。如果你刚开始接触 n8n，建议先用免费试用（Free Trial）体验一下。
{% endhint %}

{% hint style="info" %}
**国内访问提示**：n8n Cloud 的服务器部署在海外云平台，国内访问速度可能偏慢，且部分网络环境可能无法直接打开 n8n 官网或 Cloud 控制台。如果你身处国内，建议先测试网络连通性，再决定是使用 Cloud 还是自托管方案。
{% endhint %}
